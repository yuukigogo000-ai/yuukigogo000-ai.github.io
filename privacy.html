プライバシーポリシー

最終更新: 2026年8月17日

先に結論
  • このサイトにサーバーはありません。GitHub Pages が静的ファイルを配信しているだけで、入力内容を受け取る仕組みを持っていません。
  • アクセス解析・広告・追跡用の Cookie は一切入れていません。
  • ただし3つのツールだけは外部サービスへ直接データを送ります(Replier → Anthropic / JAN→楽天価格 取得ツール → 楽天 / 波チェック → Open-Meteo)。下で個別に説明します。

1. 運営

個人が趣味・研究として制作・公開しています。連絡は GitHub の Issues へお願いします。

2. サイト全体に共通すること

サーバーを持っていません

各アプリはすべてブラウザの中だけで動きます。入力した文章・画像・設定は、下の第3章で「送信あり」と書いたものを除き、あなたの端末から出ません。運営者がそれらを見ることはできません(見る手段がありません)。

ホスティング事業者のアクセス記録

このサイトは GitHub Pages(GitHub, Inc.)で配信しています。ページを開くと、通信の性質上 GitHub 側に IP アドレス・ブラウザの種類などの記録が残る場合があります。これは GitHub の管理下にあり、運営者は閲覧できません。詳しくは GitHub のプライバシーに関する声明をご覧ください。

解析・広告・Cookie

アクセス解析ツール(Google Analytics 等)、広告、SNS のトラッキングタグは使用していません。Cookie も使用していません。データの保存にはブラウザの localStorage / IndexedDB を使いますが、これらはサーバーへ自動送信されない仕組みです。

Replier(返信コーチ)

このアプリは AI に返信文を作らせるものなので、入力した会話とスクリーンショットは Anthropic 社の API に送信されます。ここは仕組み上どうしても必要な送信です。

  • 送信はあなたのブラウザから Anthropic へ直接行われます。当サイトを経由しません(経由するサーバーがありません)。
  • 使われるのはあなた自身が用意した API キーです。利用料はあなたと Anthropic の間で発生します。
  • 送信先での取り扱いは Anthropic の規約に従います → Anthropic Privacy Policy
  • Anthropic 以外の宛先へは何も送りません(解析も外部保存もありません)。
お願い: 送るスクリーンショットには相手の氏名・写真・連絡先が写ることがあります。他人の個人情報を含む画像を送るかどうかは、あなたの判断と責任になります。不要な部分は隠してから貼り付けることをおすすめします。

JAN→楽天価格 取得ツール(トップページ)

入力した JAN コードと、あなたが入力した楽天 API の applicationId / accessKey を、ブラウザから楽天のAPIへ直接送って価格を取得します。当サイトのサーバーには送られません(サーバーがありません)。楽天側の取り扱いは 楽天グループのプライバシーポリシーに従います。

波チェック(サーフ予報)

波・風・潮の予報を取得するため、表示するスポットの緯度・経度と日付を Open-Meteo の API へ ブラウザから直接送ります。当サイトのサーバーには送られません(サーバーがありません)。

  • 送るのはスポットの座標であって、あなたの現在地ではありません。このアプリは端末の位置情報(GPS)を要求しません。
  • 自分で追加したスポットの座標も、予報を取得するときに同じように送信されます。
  • 送信先での取り扱いは Open-Meteo の規約に従います。

セトリズム(バンド用セトリ設計)

外部への送信はありません。曲・セットリスト・録音はすべて端末内に保存されます。

共有リンクについて: セトリの共有リンクは、セトリの中身そのものを URL に埋め込んだものです(サーバーに保存する方式ではありません)。そのためリンクを渡した相手は中身を読めますし、SNS などに貼れば誰でも読めます。公開したくない内容を含むセトリのリンクの扱いにはご注意ください。

パチスロ帝国

外部への送信はありません。セーブデータは端末内に保存されます。

HONMONO

外部への送信はありません。画像の判定はすべてブラウザの中で行われ、画像が端末から出ることはありません(判定に使うモデルのファイルを当サイトから読み込むだけです)。ページ内から Google レンズ等へのリンクを押した場合は、その先は各社のサービスであり、このポリシーの対象外です。

デスクトップ版(セトリズム / パチスロ帝国)

Electron 版も Web 版と同じ仕組みで、データはアプリ内に保存されます。外部への送信はありません。

5. 保存されたデータの消し方

  • アプリ内に用意された操作(Replier の設定シートのキー削除・履歴クリア、パチスロ帝国の「最初からやり直す」など)を使う
  • ブラウザの設定から、このサイト(yuukigogo000-ai.github.io)の「サイトデータ」を削除する

運営者側にデータの控えは存在しません(受け取る仕組みがありません)。したがって端末から消せば、このサイトに関してはそれで消えます。復元はできませんので、セトリズムのデータは事前のバックアップ書き出しをおすすめします。

送信済みのデータは対象外です。 Replier で Anthropic に送った会話やスクリーンショット、JAN→楽天価格ツールで楽天に送った内容は、すでに相手方に渡っており、端末側の削除では消えません。それぞれの削除・保存期間については各社の方針に従ってください(Anthropic / 楽天)。当運営者には削除を代行する手段がありません。

6. 年齢について

Replier は恋愛・マッチングアプリでの会話を扱うため、18歳未満の方の利用を想定していません。

7. このポリシーの変更

機能の追加や変更にあわせて内容を更新します。更新した場合はこのページの「最終更新」の日付を書き換えます。送信先が増えるなど重要な変更があった場合は、該当アプリ内でもお知らせします。
