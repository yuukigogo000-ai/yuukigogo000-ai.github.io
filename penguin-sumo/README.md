# ペンギンずもう

氷の上のペンギンを上下左右に滑らせて、敵を氷の外へ押し出すターン制のローグライト。
おはじきバトルの検証で分かったことを、マス目の上で作り直したもの。

- **1 手の入力は向きだけ。** 何かにぶつかるまで滑るので、止まる場所まで含めて 1 手で決まる
- **指の精度に頼らない。** マス目なので狙いのズレが起きない(おはじきバトルで一番の弱点だった部分)
- **助走 − 相手のおもさ = 押す距離。** 氷の外や穴に落とせば、体力が残っていても退場
- **敵は次の行動を予告する。** 赤いマスが次に攻撃される場所、数字が行動までのターン数
- **自分では落ちない。** ペンギンは氷のふちで止まる。落ちるのは穴に入ったときと、押し流されたときだけ
- **フロアは自動生成し、探索で「解けること」を確かめてから出す。** 内容の量への備え

## 遊び方の全体

3 エリア × 5 フロア(5 つめはボス)。フロアに勝つたびに 3 つの強化から 1 つ選ぶ。ハートは 3 つ。
目標ターン数以内に勝つ「はやわざ」でハートが 1 つ回復し、ボスを倒すと全回復する。
「きょうの氷」は、その日の日付で決まる同じ並びに挑戦するモード。途中のランはこの端末に保存され、続きから遊べる。

## ファイル

| ファイル | 中身 |
|---|---|
| `src/core.js` | ルール(盤面・滑る・押す・敵の行動・ボス・強化)。依存なし・乱数なし |
| `src/solver.js` | 探索(解けるかの確認、目標ターン数、ヒント、模擬の打ち手) |
| `src/run.js` | ランの進行(フロアの自動生成、強化の候補、クリア後の処理、日替わりの種) |
| `src/ui.js` + `src/page.html` | 画面と入力(見た目は仮) |
| `build.mjs` | 1 ファイルに組み立てる → `index.html`(そのまま開ける)と `artifact.html` |
| `test.mjs` | 検査。`node test.mjs --mutate` |
| `balance.mjs` | 通しプレイのバランス確認。`node balance.mjs [ラン数]` |
| `browser-check.mjs` | 実ブラウザでの通しプレイ。`NODE_PATH=$(npm root -g) node browser-check.mjs` |

## 確かめたこと(2026-11-15)

- `node test.mjs --mutate`: 51 件合格。180 フロアを生成してすべて解けること、同じ種なら同じフロアになること、
  でたらめな手 200 フロアで盤面が壊れないことを含む。
- `node balance.mjs 40`:

| 打ち手 | 勝率 | 平均クリア |
|---|---|---|
| 上級者(探索の勝ち筋どおり) | 100% | 15 フロア |
| 3 手先まで読む・ミスなし | 63% | 12.5 |
| 2 手先まで読む・1 割は適当 | 28% | 9.1 |
| 1 手先だけ・2 割は適当 | 0% | 3.3 |

  下の 2 つの負けの多くは「50 ターン以内に倒しきれず氷がとけた」もので、模擬の打ち手の弱さによる。
  人が遊んだときの難しさは、まだ分からない。
- 実ブラウザ(360×800 / 390×844、明暗): タイトルから全 15 フロア制覇まで通しで動き、エラーなし、はみ出しなし。

## 効果音とオフライン対応(2026-11-15 追加)

- 効果音は音声ファイルを使わず、その場で合成する。タイトル画面の「音: オン / オフ」で切り替え、設定は端末に残る
- `manifest.webmanifest`・`icon.svg`・`sw.js` を置いた。サイトとして配信されているときだけ `sw.js` を登録し、1 回開けば次からは通信なしで開ける
- 確認: `NODE_PATH=$(npm root -g) node offline-check.mjs`(小さなサーバーで配信し、通信を切って再読み込み。続きからの再開も確認)
- 中身を更新したら `sw.js` の `CACHE` の番号を上げる
