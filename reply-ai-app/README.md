# Replier(リプライア)— 事業計画メモ & MVP

> 📐 **設計図・機能マップ・使い方は [DESIGN.md](DESIGN.md)**、競合調査(Rizz / YourMove AI)は [RESEARCH.md](RESEARCH.md) を参照。本書は事業背景のメモ。

**ターゲット**: マッチングアプリでアポ(デート)を取りたい男性
**製品の形**: 会話を貼り付けると、デートに繋がる返信をAIが3案提案する「返信コーチ」アプリ

## なぜ「LINE全自動返信」ではなくこの形なのか

当初の「LINE自動返信」を、この用途でそのまま商品化するのは不可能です。

| 問題 | 内容 |
|---|---|
| 技術的に不可能 | LINEの公式API(Messaging API)は**公式アカウント専用**。個人のLINEアカウントを自動返信させる公式な手段は存在しない |
| バレる | 公式アカウントで女性とやり取りすると、相手の画面に「公式アカウント」と表示され、その時点で終了 |
| 垢BANリスク | 非公式ツールで個人アカウントを自動化するのはLINE利用規約違反。ユーザーのアカウントが凍結されたら大クレームになり、事業として持続しない |
| マッチングアプリ側も禁止 | Tinder/Pairs/with等はすべて自動化ツールを規約で禁止 |

一方、**「AIが返信を提案し、送信は本人がする」形は合法かつ実績のある市場**です:

- 🇺🇸 **Rizz** — この形でVC調達、数百万DL
- 🇺🇸 **YourMove AI** — 月額課金で黒字運営
- 日本語圏はまだ強いプレイヤーが少ない = チャンス

さらにこの形なら、マッチングアプリ内の会話にも、LINE移行後の会話にも両方使えます(コピペするだけなので)。

## 現在のもの(Replier v2)

公開先: https://yuukigogo000-ai.github.io/reply-ai/

- ソースは `reply-ai-app/`(React + TypeScript + Vite)。`npm run build` の結果を `reply-ai/` に置き、GitHub Pagesがそのまま配信する
- 使い方・画面の説明は [DESIGN.md](DESIGN.md) の §4、設計と進捗は同 §2〜3

**機能**: スクショ(最大6枚)またはテキストから返信3案 / ゴール8種・トーン4種・吹き出しの分け方3種 / 脈あり度と戦略アドバイス / 各案の理由表示 / 別案の再生成 / 採用した文による文体学習 / プロフィール添削・bio生成 / PWA(ホーム画面に追加)/ ダークモード

**制約**: 検証版のため、ユーザーが自分のAnthropic APIキーを入れる方式です。**このままでは一般ユーザーに売れません**(一般人はAPIキーを持っていないため)。売るにはPhase 2(バックエンド+ログイン+課金)が必要です。

## 販売可能な製品にするためのロードマップ

### Phase 1: 需要検証(いまここ)
- 実際の会話で使って提案品質を磨く(実ユーザー2〜3人の確保が最大のボトルネック)
- X(Twitter)やマッチングアプリ攻略系の発信でLPを作り、事前登録を集める
- **課金してでも使いたい人が本当にいるか**を確認してから作り込む

### Phase 2: 製品化(バックエンド追加)
静的サイトのままでは売れないため、最小構成のサーバーを追加:

```
ユーザー → Webアプリ(スマホ対応) → 自前API(Cloudflare Workers 無料枠〜)
                                      ├─ Anthropic API(キーはサーバー側で秘匿)
                                      ├─ ユーザー認証(Google/LINEログイン)
                                      └─ Stripe(サブスク課金)
```

- **料金モデル案**: フリーミアム(無料: 1日3回まで / 有料: 月980〜1,980円で無制限+スクショ読み取り)
- **原価**: 1回の提案あたりAPI代 約1〜3円 → 月額980円でも十分な粗利
- ~~キラー機能: スクショ自動読み取り~~ → **MVPで実装済み**

### Phase 3: 拡張
- LINE会話のスクショ対応を前面に出す(アプリ→LINE移行後が本当の勝負所のため。競合2社とも未対応の空白地帯 — RESEARCH.md参照)
- ~~プロフィール文の添削 / 初回メッセ生成~~ → **MVPで実装済み**
- パーソナライズ学習(採用された案を記録し、次回生成に反映)
- ~~iOSキーボードアプリ化~~ → **取り下げ**。調査の結果、Rizz本体はキーボード拡張なしのスクショ方式で750万DLに到達しており(キーボード型は別会社の類似アプリ)、スクショフローの磨き込みが本線と判明

## 法務・信頼面の注意(売る前に必ず)

- 特定商取引法に基づく表記、プライバシーポリシー、利用規約の整備
- 「自動返信」「なりすまし」を謳わない(規約違反幇助になる) — 「返信コーチ」「会話アシスタント」として売る
- 嘘の自己紹介や相手を騙る提案はAIにさせない(MVPのプロンプトに組み込み済み)。これは倫理面だけでなく、炎上リスク回避=事業防衛でもある
