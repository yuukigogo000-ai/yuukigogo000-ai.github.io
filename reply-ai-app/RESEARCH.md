# 競合調査: Rizz / YourMove AI(2026年8月)

米国で成功している2つのAIデーティングアシスタントの調査結果と、本アプリ(Replier)への示唆。

## 1. Rizz(rizz.app / Rizz Labs)— 規模追求型

**何のソフトか**: マッチングアプリの会話やプロフィールの**スクショをアップすると、気の利いた返信案を生成**するモバイルアプリ(iOS/Android)。2023年1月ローンチ、NY拠点、完全ブートストラップ。

**使い方の流れ**:
1. デートアプリ側で会話 or プロフィールのスクショを撮る
2. Rizzにアップロード(1枚ずつのみ・テキスト補足不可)
3. トーン選択(通常/過激系など)→ 返信候補を提示、何度でも再生成
4. コピーして元アプリに貼って送信

**できること**: 返信生成 / 初回メッセージ生成 / 会話停滞時の展開案 / 「デートに誘うタイミング」「見切るタイミング」の助言 / プロフィール添削 / 使うほどユーザーの好みを学習

**ビジネス**: 累計750万〜1,000万DL、アクティブ150万人、月商$500K・累計収益$15M+、TIME誌Best Inventions 2024。ユーザーの65%が男性、主に18〜25歳。
**課金**: 実質無料枠なし。オンボーディング直後にペイウォール。週$6.99(トライアルONで7日無料→週$9.99)。週課金主体。
**成長戦略**: 有料広告ほぼゼロ。**顔出し不要のTikTokクリエイター網に再生数連動報酬(1,000再生$1〜2)を払い、「Rizzで返信を作る様子」自体を動画コンテンツ化**。支払総額$200万超で累計50億再生を獲得。

**批判されている点**: 「generic・繰り返しが多い・狙いすぎ」というAI臭さ / スクショ1枚制限 / 解約トラブル / 「アプリで盛った会話を対面で再現できずデートで失望させる」報道(WaPo/Vice)

## 2. YourMove AI — ニッチ独立経営型

**何のソフトか**: Web中心のAIデーティングアシスタント。2022年創業、元Opendoorデータサイエンティストのほぼソロ運営(+業務委託10名程度)、外部調達なし。ピーク月商$30K・粗利80%で、その後**売却済み**。

**使い方・できること**:
- **Texting Assistant**: 相手プロフィールのスクショ→約5秒で**パーソナライズされた初回メッセージ3案**。会話スクショ or テキスト貼り付け→返信生成。トーン指定(flirty/friendly/funny/feisty/formal)
- **Profile Writer / Review**: 質問に答えるとbio生成。写真・bioへの具体的フィードバック
- **AI Photos**: 自撮り→AI強化写真(サブスク外の買い切り課金)

**課金**: フリーミアム。**無料枠は1日7メッセージ程度**、Premiumは週$1.50〜$3.75相当(時期により月$12.99等)。
**成長戦略**: **PR(CNBC/WSJ/NPR等)→被リンク→SEO**。無料ツール(プロフィールジェネレーター等)+攻略ブログ記事で検索流入の約50%を獲得。

**批判されている点**: 「生成文がややジェネリックで手直しが要る」 / **AI写真は「金の無駄」と酷評が集中** / 提案の理由を説明しないためユーザーが上達せずアプリ依存になる

**プロンプト設計の公開知見(創業者談)**: 初期モデルは「誘いが強引すぎる」「プロフィールの全要素に触れようとする」「距離を詰めるジョークがcreepyになる」問題があり、「flirty but not too flirty」に長期チューニングした。

## 4. 軌道修正すべきこと

1. **iOSキーボード化はロードマップから降格**。Rizz本体はキーボード拡張を持たず、スクショ方式で750万DLに到達している(キーボード型は別会社の類似アプリ)。「キーボード=Rizzの戦略」という当初の想定は誤り。スクショフローの磨き込みが本線。
2. **AI写真機能は作らない**。YourMoveで最も酷評が集中した機能であり、追加課金設計への不満も強い。
3. **「AI臭さ」は業界全体の未解決課題**(Rizz「generic/repetitive」、YourMove「手直しが要る」が最頻出批判)。つまり本アプリの**文体ミラーリング(本人の癖をコピーする)アプローチは正しい差別化軸**。ここに投資を集中する。
4. **「デートで失望させる」問題への備え**: WaPo/Viceが「AIで盛った人がデートで化けの皮が剥がれる」と批判報道。→「別人を演じさせない(文体ミラーリング)」「理由を見せて本人を上達させる」という設計をマーケティングの防御線としても前面に出す。
5. **日本市場の空白 = LINE**。両社ともTinder/Hinge/Bumble+iMessage文化圏で、**LINEのトーク画面スクショに最適化した競合は不在**。日本ではアプリ内→LINE移行後が本番なので、「LINEスクショ対応」を最大の訴求点にする(自動返信ではなく提案なので規約リスクもない)。
6. **解約・課金周りの信頼設計**: Rizzは解約トラブルの苦情が多い。日本で同じことをやると致命傷になりやすい(特商法+レビュー文化)。ワンタップ解約を明示する。
