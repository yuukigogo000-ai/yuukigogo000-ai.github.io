# 1. 完成系のビジョン

**「マッチングアプリでアポを取りたい男性のための、日本初のLINE対応AI会話コーチ」**

> スクショを撮って投げるだけで、"本人が打ったとしか思えない"返信が3案返ってくる。
> マッチ〜初回メッセ〜会話〜LINE移行〜デート打診〜デート後まで、全行程を1つのアプリでコーチする。

## 競合(Rizz / YourMove AI)に対する3つの差別化軸

| 軸 | 内容 | 根拠 |
|---|---|---|
| ① 文体ミラーリング | 本人の過去メッセージから文体の癖(敬語/タメ口・絵文字・句読点・テンション)を抽出して完全コピー。「AI臭い・generic」という両競合への最頻出批判に真正面から答える | RESEARCH.md §4 |
| ② LINE最適化 | 両競合とも欧米アプリ+iMessage圏。日本の「アプリ→LINE移行後が本番」に最適化した競合は不在 | RESEARCH.md §4-5 |
| ③ 上達する設計 | 全提案に「なぜ効くか」を表示。「ユーザーが上達せずアプリ依存になる」批判(YourMove)と「デートで化けの皮が剥がれる」批判報道(WaPo/Vice)への回答であり、マーケの防御線 | RESEARCH.md §4 |

# 4. 説明書(いまのアプリの使い方)

公開先: https://yuukigogo000-ai.github.io/reply-ai/

## 準備(初回のみ)
1. https://console.anthropic.com/ でAPIキーを取得(`sk-ant-` で始まる文字列)
2. アプリ右上の歯車 → 「Anthropic APIキー」に貼り、「このブラウザに記憶する」にチェック
   - チェックが入っていれば**入力した時点で保存**される(生成前にページを閉じても消えない)
   - キーに有効期限を付けた場合、切れると「認証エラー」になる。作り直して貼り直せばよい
3. スマホなら「ホーム画面に追加」。URLバーが消えて全画面で開き、アイコンは `Replier` と表示される

## 返信提案タブ

1. **会話を読み込む**
   - トーク画面のスクショを最大6枚(LINE / Pairs / Tinder など。**右側=自分**として読み取る)
   - またはテキストで貼り付け。スクショとの併用も可
   - 「動作確認用のサンプル会話」を選ぶと、会話・相手プロフィール・文体・ゴールが一式入る(架空の会話)
2. **相手のプロフィール**を入れると精度が上がる(任意)
3. **今回のゴール**を選ぶ(8種)
   会話を盛り上げる / デートに誘う / 既読スルー対策 / 初回メッセージ / 日程調整 / デート前日・当日 / デート後お礼 / LINE交換
   - 「初回メッセージ」だけは**会話が空でも作れる**(相手のプロフィールか自分の文体サンプルがあればよい)
4. **トーン**は基本「自分の文体に合わせる」のまま。**吹き出しの分け方**は「おまかせ」で問題ない
   - 「1通にまとめる」を選ぶと、AIが分けて返しても**必ず1通に丸める**(マッチングアプリ内向き)
   - 「分けて送る」はAIへの指示。場面によっては1通で返ることがあり、その時は注記が出る
5. 必要なら「詳細設定」に追加の指示(例:今週の土曜に誘いたい)や普段の文体サンプルを入れる
6. **返信案を3つ作る**を押す
   - 「会話を読み取っています → 文体を分析しています → 返信案を作っています」と進行が出る
   - 終わると自動で結果までスクロールする
7. 結果を見る:**いまの状況** / **送信プレビュー(3案)** / **次の一手**
8. 使う案を**コピー**(複数通に分かれている案は「1通ずつ」も「まとめて」も可)→ 相手のアプリに貼って送信
9. しっくりこなければ「**方向性を変えて別の3案**」(既出案をAIに渡すので同じ案は出にくい)

**コツ**
- スクショは数往復ぶん入れると文体の再現が効く
- コピーした文は「本人が採用した文」として**このブラウザに最大30件記憶**され、**次回以降の生成に直近8件が渡る**(使うほど自分寄りになる。詳細設定から消去可)

## プロフィール添削タブ
1. プロフィール画面のスクショ(写真+自己紹介文が写っているとベスト)、または自己紹介文を貼り付け
2. **自分の基本情報**を入力 — 改善案は**この事実だけ**で作られる(盛らない)
3. 「今のプロフィールを診断」か「ゼロから作る」を選んで実行
4. 得点・第一印象・良い点・直すべき点・改善案2案・写真アドバイスが出る

## 画面に出る注記の意味

| 表示 | 意味 |
|---|---|
| 入力が変わったので、前の提案は表示していません | 提案を作った後に会話や設定を変えた。**古い相手向けの案を誤って送らないため**に隠している。もう一度押せば作り直す |
| AIから◯案しか返りませんでした | 3案揃わなかった。「別の3案」で出し直せる(API側の仕様で3案を強制はできない) |
| 「分けて送る」を選びましたが、AIは1通で返しました | その場面では分けない方が自然と判断された |
| コピーできませんでした | ブラウザがコピーを拒否した。文面を長押しして手動でコピーする(**この場合は文体学習にも記録しない**) |
| コピーしました(履歴は保存できませんでした) | プライベートブラウズ等で保存できない。今回の生成には使われるが、次に開くと消える |
| 応答がありませんでした(時間切れ) | 2分待っても返らなかった。通信を確認してもう一度 |
| 新しい版が公開されています | 更新がある。**押すまでリロードしない**(入力中の会話は消えない) |

## 注意事項
- 提案は参考。送信は必ず自分の判断で(**自動送信はしない・できない設計**)
- 嘘の経歴・趣味を盛る提案はAIに禁止済み
- スクショと会話はAI処理のためAnthropicにのみ送信。このサイトにサーバーは存在しない
- LINEはLINEヤフー株式会社の登録商標。本アプリは同社およびマッチングアプリ各社とは無関係

## 品質チューニングの評価軸(Phase 1.5)
- **AI臭さ**: 生成文を第三者に見せて「AIか人か」を当てられない率
- **文体一致**: 本人の過去メッセと絵文字頻度・語尾・句読点が一致しているか
- **アポ転換**: 「デートに誘う」案が会話の文脈に紐づいているか(唐突な誘い率0を目標)

## 破壊的検証(2026-08-17)
Codexによる読み取り専用レビューを6ラウンド実施し、指摘34件のうち31件を修正、3件は理由をつけて見送り、最終ラウンドで PASS。
E2Eは131項目に拡張し、重要な修正は変異注入で「テストが実際に落ちる」ことを確認済み。詳細は [REVIEW_LOG.md](REVIEW_LOG.md)。

## 未検証の残リスク
- **実APIでの通し確認は所有者による数回のみ**(2026-08-17)。E2Eはすべてモック応答なので、モデルの実出力の質は自動テストでは担保されない
- 実機(iPhone/Android)でのタッチ操作・PWAインストールは未確認
- 応答本文の受信が途中で止まる経路は、コードは対処済みだがPlaywrightで再現できないため自動テストが無い
- テスト用の逃げ道として localStorage `reply_ai_timeout_ms` でタイムアウトを短縮できる(本番では未使用)
