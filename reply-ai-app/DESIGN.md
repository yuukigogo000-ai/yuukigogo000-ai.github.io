# 1. 完成系のビジョン

**「マッチングアプリでアポを取りたい男性のための、日本初のLINE対応AI会話コーチ」**

> スクショを撮って投げるだけで、"本人が打ったとしか思えない"返信が3案返ってくる。
> マッチ〜初回メッセ〜会話〜LINE移行〜デート打診〜デート後まで、全行程を1つのアプリでコーチする。

## 競合(Rizz / YourMove AI)に対する3つの差別化軸

| 軸 | 内容 | 根拠 |
|---|---|---|
| ① 文体ミラーリング | 本人の過去メッセージから文体の癖(敬語/タメ口・絵文字・句読点・テンション)を抽出して完全コピー。「AI臭い・generic」という両競合への最頻出批判に真正面から答える | RESEARCH.md §4 |
| ② LINE最適化 | 両競合とも欧米アプリ+iMessage圏。日本の「アプリ→LINE移行後が本番」に最適化した競合は不在 | RESEARCH.md §4-5 |
| ③ 上達する設計 | 全提案に「なぜ効くか」を表示。「ユーザーが上達せずアプリ依存になる」批判(YourMove)と「デートで化けの皮が剥がれる」批判報道(WaPo/Vice)への回答であり、マーケの防御線 | RESEARCH.md §4 |

# 3. アーキテクチャ

## 現在(MVP / Phase 1.5)

```
reply-ai-app/          ← ソース(React + TypeScript)
  src/lib/             … prompts.ts(指示書) samples.ts api.ts images.ts storage.ts
  src/components/      … ReplyTab / ProfileTab / SettingsSheet / Dropzone / ReplyCard ほか
  tests/e2e.test.js    … 実ブラウザ+モックAPIの破壊的検証 79項目
        │ npm run build (Vite)
        ▼
reply-ai/              ← ビルド結果(GitHub Pagesがそのまま配信)

実行時:
ユーザーのブラウザ
 ├─ スクショをcanvasで縮小(最大辺1400px/JPEG)… 通信量・トークン節約
 ├─ ユーザー自身のAnthropic APIキー(localStorage任意保存)
 └─ fetch → Anthropic API(claude-opus-5)へ直接
      ├─ 構造化出力(output_config.format = json_schema)で堅牢にパース
      ├─ システムプロンプトは cache_control: ephemeral
      ├─ 返信モード: REPLY_SYSTEM + REPLY_SCHEMA
      └─ プロフモード: PROFILE_SYSTEM + PROFILE_SCHEMA
※ 自前サーバーなし。画像・会話はAnthropic以外のどこにも送信されない
```

**開発コマンド**(`reply-ai-app/` で実行)

```bash
npm install
npm run dev                     # 開発サーバー
npm run build                   # ../reply-ai へビルド(公開物)
python3 -m http.server 8778     # リポジトリのルートで起動(テスト用)
npm test                        # E2E 79項目
npm run icons                   # アイコンPNGを favicon.svg から再生成
```

## 完成系(Phase 2以降)

```
ユーザー(スマホWeb / PWA)
   │ Google/LINEログイン
   ▼
Cloudflare Workers(API)
   ├─ 認証・セッション
   ├─ 無料枠カウント(KV)・サブスク判定
   ├─ Stripe(週/月サブスク, Webhook)
   ├─ Anthropic API呼び出し(キーはサーバー秘匿)
```

**移行方針**: API呼び出しは `src/lib/api.ts` の1関数に集約済み。向き先を自前APIに差し替えるだけで移行できる。

# 4. 説明書(現MVPの使い方)

## 準備(初回のみ)
1. https://console.anthropic.com/ でAPIキーを取得(`sk-ant-`で始まる)
2. 右上の歯車 → 「Anthropic APIキー」に貼る(「このブラウザに記憶する」推奨)
3. スマホなら「ホーム画面に追加」でアプリとして開ける

## 返信提案タブ
1. **会話を読み込む**: トーク画面のスクショを最大6枚(LINE/Pairs/Tinder等。右側=自分として自動判別)。またはテキストで貼り付け。併用も可
2. 相手のプロフィール情報があれば入力(精度UP)
3. **ゴールを選ぶ**(8種)→ **トーン**は基本「自分の文体に合わせる」のまま
4. 必要なら詳細設定で追加指示・文体サンプルを入れる
5. 生成 → 脈あり度と状況分析を確認 → 3案から選んでコピー → アプリに貼って送信
6. しっくりこなければ「方向性を変えて別の3案」

**コツ**: スクショは数往復分入れると文体学習の精度が上がる。コピーした案は自動的に文体学習に使われる(設定不要)。

## プロフィール添削タブ
1. プロフィール画面のスクショ(写真+bioが写っているとベスト)or 自己紹介文を貼り付け
2. **自分の基本情報**を入力(改善案はこの事実だけで作られる=盛られない)
3. 「今のを診断」or「ゼロから作る」を選んで実行

## 注意事項
- 提案は参考。送信は必ず自分の判断で(自動送信はしない・できない設計)
- 嘘の経歴・趣味を盛る提案はAIに禁止済み
- スクショはAI処理のためAnthropicにのみ送信。このサイトにサーバーはない

## 品質チューニングの評価軸(Phase 1.5)
- **AI臭さ**: 生成文を第三者に見せて「AIか人か」を当てられない率
- **文体一致**: 本人の過去メッセと絵文字頻度・語尾・句読点が一致しているか
- **アポ転換**: 「デートに誘う」案が会話の文脈に紐づいているか(唐突な誘い率0を目標)

## 破壊的検証(2026-08-17)
Codexによる読み取り専用レビューを6ラウンド実施し、指摘34件のうち31件を修正、3件は理由をつけて見送り、最終ラウンドで PASS。
E2Eは131項目に拡張し、重要な修正は変異注入で「テストが実際に落ちる」ことを確認済み。詳細は [REVIEW_LOG.md](REVIEW_LOG.md)。
