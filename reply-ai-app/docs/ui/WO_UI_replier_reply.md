## 2. 交通整理(Claude が決定 → 発注者に提示)

| 問い | 決定 | 理由 |
|---|---|---|
| 主操作は1つだけ、何? | **トーク画面のスクショを読み込んで、返信案を作る** | 実在アプリ3本(Flair/UpTalk/RIZZ)すべて入口を1つに絞っている。現状は選択チップ15個が同時に見えて主操作が埋もれている |
| 上位3タスク(頻度順) | ①案を作る ②案をコピーする ③別の3案を出す | 1回の利用で必ず通る道 |
| 格下げ/隠す | ゴール8・トーン4・分け方3 → **「今回の狙い: … ▾」の1行**に折りたたむ(既定値で使える)。サンプル会話・詳細設定も同様に格下げ。**結果が出たら入力欄はサマリ1行に畳む** | 差別化機能なので消さずに格下げ。結果を見る時に入力は不要 |

| 使う場面 | 片手・立位・急ぎ・人目が気になる(電車内) | ホーム画面から開いて数十秒で使う |

## 5. デザイン仕様(見本の言語化)

1. **アプリバー**: 左「Replier」(fs-1相当の太字)+ 補足1行(fs-4)、右に設定アイコン(48×48のヒット領域)
2. **セグメント**: 返信提案 / プロフィール添削(高さ48)
3. **入力(結果が無いとき)**: 点線枠の大カード(スクショ追加)→ 補助リンク2つ(テキスト貼付・サンプル)→「今回の狙い: … ▾」1行
4. **入力(結果があるとき)**: 「スクショN枚 ・ 狙い: …」の1行サマリ + 右端「変更」
5. **結果**: いまの状況カード(見出しfs-4+本文fs-3+脈あり度の細バー)→「送信プレビュー / タップでコピーできます」→ 案カード3枚(右寄せ吹き出し・なぜ効くか1行・右下にコピーアイコン)→ 次の一手カード
6. **下部固定**: 主ボタン(高さ56・角丸4)。結果があるときは「方向性を変えて別の3案」を副ボタンで併置
