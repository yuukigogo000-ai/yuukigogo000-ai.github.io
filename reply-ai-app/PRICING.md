## 1. 製品の前提

- **Replier** = マッチングアプリでデートのアポを取りたい男性向けの「返信コーチ」Webアプリ(PWA)
- 会話のスクショ(最大6枚)かテキストを貼ると、**本人の文体を真似た返信を3案**+次の一手のアドバイスを返す
  - ※脈あり度・人物評価・感情推定は**出さない**。以前の決定に反して残っていた `interest_level`(プロンプト・スキーマ・UIメーター)は
    **2026-09-01に除去済み**(RESEARCH_LINE_STYLE.md §4.6)。「いまの状況」と「次の一手」の文章は残す
- 差別化: ①文体ミラーリング(AI臭さ対策) ②日本のLINE会話に最適化 ③提案の「理由」を見せて本人が上達する設計
- **AI = Kimi K2.5(Amazon Bedrock 東京リージョン)= 技術第一候補(2026-09-01)**
  - 根拠: 3モデル比較(各120ケース)+本番プロンプト追従30ケース+本番形式(tool-use)確証30ケース。Kimi単体で計184呼び出し
  - 品質: 機械評価99.7点・捏造0件・文体/吹き出し構造の追従が比較3モデル中最良・tool-use形式でschema適合30/30
  - **確定扱いにしない**: 本番形式での実測はまだ30ケース。公開前に追加30ケース(脈あり度除去後のプロンプトで)。Moonshot規約確認とあわせて**開発と並行して終わらせる**(公開のブロッカーにはするが着手のブロッカーにはしない)
  - 予備: Qwen3 VL 235B(同評価でschema事故ゼロ・品質100点。Kimi提供終了時の乗り換え先)
- **処理場所は経路ごとに分ける**:
  - AI推論(Bedrock Converse): 東京リージョン内で完結・AWSアカウントは retention none(会話を学習に使わせない設定を実測確認)
  - 決済(Stripe): カード情報はStripe側で処理(海外事業者・PCI DSS準拠)
  - 認証・監視・ログ: 採用サービス次第。設計時に保存場所と保持期間を決めてプライバシーポリシーに書く
- 構成は**サーバー側プロキシ必須**(旧「ユーザー自身のAPIキー」方式は廃止)。Webアプリなのでストア手数料(15〜30%)は不要
- 自動送信はしない(設計として不可能にしてある)

## 2. 原価(AI推論)— 実測値(2026-09-01・為替160円/$)

### 実測方法
本番と同じプロンプト+tool-use形式で合成データ30ケース(テキスト/スクショ1〜6枚)を実行し、APIのusageから算出。
平均入力6,797トークン・平均出力433トークン。単価はAWS Price List APIの公式値(入力$0.72/出力$3.60 per 100万トークン)。

| 利用パターン | 実測平均 | 実測最大 |
|---|---|---|
| テキストのみ | **0.76円** | 0.88円 |
| スクショ1〜3枚 | **1.16円** | 1.59円 |
| スクショ4〜6枚 | **1.98円** | 2.93円 |
| **全体平均** | **約1.03円** | — |

### 決済手数料(Stripe・日本・[公式料金](https://stripe.com/jp/pricing))
- 国内カード決済 **3.6%**。サブスク(Stripe Billing)はさらに **0.7%** → **合計約4.3%**
- 標準料金に「1件あたりの固定額」は確認できない(v2の記載は誤り)。単発の追加購入は3.6%

### 固定費(サーバー側プロキシ化で発生・月額)— **未実証・設計で確定**
- AWS小規模構成(Lambda/API Gateway/DynamoDB等): 無料枠内〜数百円が見込みだが**実装後に実測**するまで確定値としない
- 設計上の制約: Lambda同期呼び出しのペイロード上限は6MB([公式](https://docs.aws.amazon.com/lambda/latest/dg/gettingstarted-limits.html))。
  スクショ6枚を通すには**画像圧縮(現行アプリは最大辺1400px JPEG化済み)+サイズ検査**が必須
- 独自ドメイン: 年約1,500〜2,000円 / 監視・エラー通知: 無料枠級
- 損益試算では固定費 **月5,000円** を仮置き(保守的)

### 消費税(損益に未反映だった点の整理)
- 開始当初は免税事業者となり得るが、基準期間の課税売上高1,000万円超等で納税義務が発生([国税庁](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6501.htm))
- 消費者向け価格は**総額表示**義務 → 本資料の価格は**すべて税込表示**として扱う
- 課税事業者になった時点で、税込1,480円の税抜は約1,345円(手取りが約9%減)。§6に両パターンを載せる

### 残存リスク
- Kimi K2.5 のサポート終了日(EOL)未公表 → 終了時はQwen3 VLへ乗り換え(同評価で実証済み)
- Moonshot AI(Kimi提供元)の利用規約の法的確認が未了
- 為替160円/$固定。円安で比例して上がる(180円/$でも1回約1.2円)
- 応答時間: 平均9.5秒・まれに40秒超 → ローディング演出(現アプリの段階表示)が前提

## 3. 競合の課金(2026年8月調査・**価格は地域/時期/プランで変動する参考値**)

- **Rizz**(米): App Storeでは地域・時期・プランにより複数価格が表示される([CA版](https://apps.apple.com/ca/app/rizz/id1663430725))。調査時点の代表値は週$6.99(月換算約4,500円)。実質無料枠なし・即ペイウォール・解約トラブルの苦情多
- **YourMove AI**(米): フリーミアム(無料枠1日7メッセージ程度)。App Store表示は月$12.99([US版](https://apps.apple.com/us/app/yourmove-ai-wingman-for-dating/id6737511035))
- 示唆: 無名の新規アプリにRizz型即ペイウォールは不向き → フリーミアム。**週課金は日本では「解約忘れ狙い」に見えるリスク**(週480円=月換算約2,080円)

## 4. 日本市場の価格アンカー

- マッチングアプリ本体(男性有料・Web決済): **Pairs 1か月4,100円**([公式](https://www.pairs.lv/price))、**Omiai 1か月4,400円**([公式](https://fb.omiai-jp.com/price/))
- つまり月1,480円でも**本体料金の約3分の1**。「アポ1件増えるなら」の訴求が成立し得る
- 攻略系note・添削サービスは数千円〜1万円超でも売れている

## 5. 料金モデルの比較(原価1円/回+回数上限必須、の前提)

|---|---|---|
| 週課金 | 週480円 | **不採用**。月換算2,080円で高く、無名Webサービスの週次自動更新は信頼を損なう |

## 7. 採用案(発注者レビュー結論・2026-09-01)

| 項目 | 内容 |
|---|---|
| 通常価格 | **月1,480円(税込)**。1,980円は継続率と成果実績が出てから検討 |
| ローンチ価格 | **月980円・最初の3か月**(通常価格への移行日を明示) |
| 無料枠 | **生涯3回**。機能制限なし(スクショ機能も体験させる) |
| 有料枠 | **月150回**+**1日20回**まで。「無制限」とは書かない |
| 上限到達時 | 返信生成のみ停止。履歴・設定・過去の生成結果は閲覧可。**2択を表示**: ①次回更新日まで待つ ②追加50回を500円で購入 |
| 追加枠 | 自動更新なし・翌月繰り越し・**購入から180日で失効**・毎月の150回を先に消費 |
| 表示 | 常時「残り○回」・残り30回/10回で通知・150回到達で生成ボタン無効化・次回更新日時を表示・自動更新日と解約方法を明示 |
| 週課金 / 回数チケット | 採用しない / 初期は採用せず解約理由を見て判断 |
| 悪用対策 | 最初はメール認証+アカウント/IPレート制限+CAPTCHA。電話番号認証・デバイス指紋は**不正が実測されるまで入れない** |
| 検証順序 | 大規模A/Bを待たず980円で有料βを開始 → 課金者30〜50人後に新規だけ1,480円へ上げてCVR・継続率を比較(少量トラフィックのA/Bは判定不能) |
| 目標値 | CVRは3〜5%を確定値にせず3シナリオで管理: 悲観1% / 基準3% / 強気5% |

追加枠の採算: 50回500円のAI原価約52円。Stripe(3.6%〜4.3%)控除後、その他経費前で**約427〜431円**残る。

**法務の要確認(採用案の実装前)**:
- 有効期限付きの追加枠は**前払式支払手段**に該当し得る。金融庁は「発行日から6か月以内に限って使用できるもの」を適用除外として案内
  ([金融庁](https://www.fsa.go.jp/news/27/sonota/20151214-2.html))→ 180日失効はこの範囲内を意図した設計だが、**利用規約への明記と専門家確認が必要**
- 特商法表記(自動更新・解約方法・通常価格移行日)/ 総額表示

## 8. 数値の確度と未反映事項
