# レビュー依頼: Replier(返信コーチ)v2 — 商用UIへの全面刷新

## 何をしたか
単一HTMLファイルだった MVP を React + TypeScript + Vite + Tailwind v4 + Radix に作り替え、UIを全面刷新した。
指示書(`src/lib/prompts.ts`)とサンプル会話(`src/lib/samples.ts`)は旧版から機械移植(文言は不変)。

主な変更:
1. 画面構成: ヘッダー/タブ(返信提案・プロフィール添削)/入力カード/結果(送信プレビューの吹き出し)/固定CTA
2. 設定をボトムシート(Radix Dialog)に集約。APIキーはここで入力(localStorage任意保存)
3. 生成中の段階表示+スケルトン、完了後に結果へ自動スクロール、コピー時トースト
4. 採用学習(コピーした返信を localStorage に最大30件、次回プロンプトに直近8件を添付)
5. 吹き出しの分け方をユーザーが選択(おまかせ/1通にまとめる/分けて送る)。「1通」選択時はモデルが分割して返しても描画側で1通に丸める
6. PWA化(manifest / service worker / アイコン)、ダークモード
7. E2E 87項目(Playwright + APIモック)

## 特に見てほしい点
- 状態管理の穴: タブ切替・連打・再生成でのリクエスト内容のズレ、古い state を掴んだままの送信
- プロンプト組み立て: ゴール/トーン/分け方/文体サンプル/採用履歴/画像が正しく1回ずつ入るか
- 採用履歴の取り違え・消失(複数吹き出しコピー時、クリア時)
- Service Worker が API 通信やデプロイ後の更新を壊していないか
- エラー時にUIが詰む経路がないか
- テストが「落ちないテスト」になっていないか(モックが甘い箇所)
