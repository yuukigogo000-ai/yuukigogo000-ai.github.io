toaster-daily privacy policy and terms

toaster-daily is a small personal tool. It uploads short videos made by the owner of the YouTube channel the daydreaming toaster (@daydreamtoaster) to that same channel.

Terms of use

toaster-daily uses YouTube API Services. By using toaster-daily, you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies.

Who uses it

Only the channel owner. It does not offer sign-in to anyone else, and it has no users other than the owner.

What it accesses

It asks Google only for permission to upload videos to the owner's own YouTube channel (YouTube Data API, upload scope). It does not read viewers' data, comments, subscribers, or any other channel.

What it stores, and where

  • The OAuth client ID, client secret and refresh token are stored in a local file on the owner's own computer. The refresh token is sent only to Google's OAuth token endpoint, to get a short-lived access token. The access token is sent only to Google, with each YouTube API request.
  • toaster-daily does not keep the video ID, URL or any other data that YouTube returns. It reads the response only to check that the upload succeeded and is public. To avoid uploading the same video twice, it keeps only its own local note: the date and its own name for the video.
  • None of this is sent to any other server or shared with anyone.
  • The videos, titles and descriptions it uploads are published on YouTube by the owner's choice.

Retention and deletion

  • The tokens are kept until the owner removes them. No other data from YouTube is kept.
  • To stop the tool and delete its access: revoke the permission at Google Account permissions, then delete the YouTube entry from the local file (the owner does this within 30 days of revoking; in practice right away). Revoking the permission makes the stored refresh token useless.
  • Deleting the local data does not delete videos already on YouTube. Videos are deleted in YouTube Studio.

Ads and analytics

This tool and this page use no ads and no analytics.
