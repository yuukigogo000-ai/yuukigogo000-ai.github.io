4. 素材発注デスク

画像AI（ChatGPT・Gemini・Midjourney など）に貼るプロンプトを、このアプリのテーマから自動で作ります。どの素材も同じスタイル指定が付くので、アプリ内で作風がブレません。

5. 素材チェックリスト

このアプリで用意する素材の進捗管理。チェック状態はブラウザに保存されます。

    CSS変数（Webアプリ / PWA / Capacitor）
    Flutter（ThemeData）
    JSON（Unity・Godot 等に取込む生データ）
