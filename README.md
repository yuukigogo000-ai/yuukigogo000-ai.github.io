# yuukigogo000-ai.github.io

## セトリズム (SETLISM) — `/band/`

バンドのためのセトリ設計スタジオ。サーバー不要・インストール不要で、スマホのブラウザだけで動くPWAです。

**URL:** https://yuukigogo000-ai.github.io/band/

### 機能

- **セットリスト管理** — 曲ごとに BPM / キー / チューニング / 長さ / 盛り上がり度 / MC / メモを登録。ドラッグ(PC)や↑↓ボタン(スマホ)で並べ替え
- **持ち時間シミュレーション** — 演奏時間+曲間の転換+MCを合算し、持ち時間に対する残り・オーバーを自動計算
- **エナジーフロー** — セット全体の「盛り上がりの流れ」を曲線で可視化。MCの位置もマーカー表示。ライブの構成づくりに
- **メトロノーム** — Web Audio のルックアヘッドスケジューラによる高精度クリック。タップテンポ、拍子・刻み(8分/3連/16分)、アクセント。セトリの曲からワンタップでBPM読み込み
- **チューナー** — マイク入力の自己相関ピッチ検出によるクロマチックチューナー。A4基準ピッチ変更可(415〜466Hz)
- **共有リンク** — セトリ全体を圧縮してURLに埋め込み。リンクを送るだけでメンバーの端末に取り込める(サーバー保存なし)
- **ステージシート印刷** — ステージに貼る用の大文字セトリをA4で出力。チューニング・キー・BPM・MC位置つき
- **オフライン対応** — Service Worker によりスタジオ・ライブハウスの圏外でも動作。データは端末のブラウザに保存(バックアップの書き出し/読み込みあり)

### 技術メモ

- 依存ライブラリなしの Vanilla JS(ES Modules)。`band/` 配下の静的ファイルのみで完結
- メトロノームは `setInterval` で先の音を予約し続け、発音は `AudioContext` の時計に任せるルックアヘッド方式(揺れ防止)
- チューナーは ACF(自己相関)+放物線補間。最大ピークの90%を超える最小ラグの山を採ることでオクターブ下の誤検出を回避
- 共有リンクは `CompressionStream (deflate-raw)` + base64url。非対応ブラウザには非圧縮フォールバック
