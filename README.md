# yuukigogo000-ai.github.io

## セトリズム (SETLISM) — `/band/`

バンドのためのセトリ設計スタジオ。サーバー不要・インストール不要で、スマホのブラウザだけで動くPWAです。

**URL:** https://yuukigogo000-ai.github.io/band/

### 機能

**セトリ設計**
- **セットリスト管理** — 曲ライブラリ(持ち曲マスター)から曲を選んで構成。BPM / キー / チューニング / 長さ / 盛り上がり度 / 転換チェックリスト / メモ。並べ替え・複製・Undo/Redo対応
- **持ち時間シミュレーション** — 演奏+転換+MCを合算し、持ち時間との差を自動計算
- **エナジーフロー** — セットの「盛り上がりの流れ」を曲線で可視化。理想の型テンプレート(尻上がり型・2山型など)を重ねて一致度を表示、別セトリとのA/B比較も
- **セトリ診断** — チューニング替えの連続・同キー連続・BPM単調・エナジー急落・時間オーバーなど、構成上の注意点を自動チェック
- **持ち替えプランナー** — チューニング情報から必要な本数と持ち替えタイミングを自動算出(MCなし持ち替えを警告)

**練習**
- **通し練習モード** — セトリを頭から自動進行。各曲のBPMでクリック+カウントイン、曲が終わると転換タイマーを挟んで次へ
- **メトロノーム** — Web Audioルックアヘッドスケジューラ。タップテンポ、拍子・刻み、カウントイン、段階テンポアップ、抜き練習(クリック消失小節)
- **チューナー** — 自己相関ピッチ検出のクロマチックチューナー(A4基準可変)
- **耳コピ・ループ再生** — 音源のA-Bループ+ピッチ維持の速度変更+波形表示
- **リハ録音** — その場で録音してIndexedDBに保存。曲へのひも付け・書き出し対応

**本番**
- **本番モード(Now Playing)** — 開始打刻で「今の曲」と「押し/巻き」をリアルタイム表示。次の曲の転換チェックリスト、終演後のまとめ(予定vs実際)。リロードしても進行を復元
- **イベント・タイムテーブル** — 対バン・自主企画の進行表。各バンドの開始打刻で押しが以降の予想時刻に反映
- **ステージシート印刷** — 大文字セトリ+チェックリスト+持ち替えプランをA4出力

**共有・保存**
- **共有リンク** — セトリ全体を圧縮してURLに埋め込み(サーバー保存なし)。QRコード表示・テキストコピーにも対応
- **オフラインPWA** — Service Workerでスタジオの圏外でも動作。バックアップの書き出し/読み込みあり

### 技術メモ

- Vanilla JS(ES Modules)。外部依存はQRコード生成の [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)(MIT・`band/vendor/` にベンダリング)のみ
- メトロノームはルックアヘッド方式(`setInterval` で予約・発音は `AudioContext` の時計)。エンジンをUIから分離し通し練習モードでも共用
- チューナーは ACF(自己相関)+放物線補間。最大ピークの90%を超える最小ラグの山でオクターブ誤検出を回避
- 共有リンクは `CompressionStream (deflate-raw)` + base64url(非対応ブラウザは非圧縮フォールバック、旧形式リンクとも後方互換)
- データは localStorage(v1→v2自動マイグレーション)、録音Blobのみ IndexedDB
- Playwright(Chromium)による87項目のスモークテスト(QRの実デコード検証・v1移行・自動進行・録音まで)を全通過
