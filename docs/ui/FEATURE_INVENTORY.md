## 0. このアプリが「できないこと」(先に固定する)

Visual Reference にこれらを描かせないための一覧。

| できないこと | 理由 |
|---|---|
| 外部データの取得(相場・統計・為替・API 一切) | **外部通信ゼロ**が仕様。`fetch`/`XMLHttpRequest`/外部URL が1つも無いことを機械検査(`logic_freeze` 契約 `no_fetch`/`no_external_url`)で固定 |
| クラウド同期・ログイン・共有 | 保存は localStorage のみ。他端末へは JSON 書き出しで手動 |
| 通知・リマインド | Service Worker 無し |
| 画像・写真の表示 | 画像アセット 0 個。アイコンは自前インライン SVG 14 個のみ |
| 実績の記録と答え合わせ | **未実装**(定義書 v0.2 の v2 候補) |
| モンテカルロ / 確率分布 | **未実装**(同上)。現在は 3 点シナリオのみ |
| 選択肢どうしの排他・依存関係 | **未実装**(同上)。組合せチェックは単純な足し算 |
| 税・社会保険料の計算 | **していない**。効果額はユーザーが手取りベースで入れる前提 |
| インフレ調整 | **していない**。割引率で一括表現 |

→ **「更新中」「同期しました」「オフライン」「読み込み中」の状態表現は不要**。ローディングが存在しない。

## 4. 計算(これが中身。UI で触らない)

```
costPV      = 初期コスト + 継続コスト×12×annuity(投入期間, r)
シナリオ価値 = 効果額 × 強気度 × annuity(効く年数, r) − costPV
EV          = Σ 確率ᵢ × シナリオ価値ᵢ
最悪ケース   = min(シナリオ価値)
損益分岐確率 = −最悪 / (最良 − 最悪)   ※全部プラスなら0・全部マイナスなら1
時間対効果   = EV ÷ (月時間×12×投入期間)   ※時間0なら null(「—」表示)
資金対効果   = EV ÷ 総コスト               ※コスト0なら null
```
`annuity(n, r) = n<=0 ? 0 : r<=0 ? n : (1 − (1+r)^−n) / r`

**判定**
- 制約チェック5種: 一時金上限 / 月あたり資金上限 / 月あたり時間上限 / 最悪ケースが許容損失超え / 最長年数が残り活動年数超え
- `EV ≤ 0` → **見送り** / 制約に抵触 → **条件付き** / それ以外 → **有望**
