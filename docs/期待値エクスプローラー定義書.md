# 期待値エクスプローラー（Personal Expectation Explorer）定義書

版: v0.2 / 作成日: 2026-08-16
（v0.1 のせどり・ポイ活・キャンペーン前提を廃止し、マクロ視点の意思決定探索ツールとして再定義）

## 1. 一文定義

**個人が自分のリソース（お金・時間・エネルギー・スキル・リスク許容度）を前提として登録し、人生レベルの選択肢 —— キャリア、学習、資産形成、健康、住まい、独立など —— の「期待値」を長期の時間軸で見積もり・比較・探索できる、ブラウザ完結の個人用意思決定ツール。**

短期の小銭稼ぎ（せどり・ポイ活・キャンペーン）は対象外。**「今後5〜30年の自分にとって、どこにリソースを張るのが割に合うか」** を総括的に俯瞰するためのツール。

## 2. 背景と課題

- 個人の重要な意思決定（転職するか、資格を取るか、投資に回すか、移住するか）は、影響が大きいのに感覚と勢いで決められがち。
- 選択肢ごとに「かかるコスト」「起こりうる結果とその確率」「効いてくる期間」がバラバラで、頭の中だけでは比較できない。
- 個人のリソースは有限。**すべての選択肢は他の選択肢の機会費用**であり、単体の善し悪しではなく「自分の制約の中での相対比較」が必要。
- 必要なのは精密な予測ではなく、**桁と順位を間違えないための粗い見積もりと、前提を動かして眺められる探索環境**。

## 3. 用語定義

| 用語 | 定義 |
|---|---|
| 選択肢（オプション） | 評価対象となる1つの大きな意思決定。例：「転職する」「大学院に行く」「インデックス投資を月5万にする」「地方に移住する」 |
| シナリオ | 1つの選択肢の結果の分岐。最低3点（悲観 / 中位 / 楽観）で各々に確率と結果を割り当てる |
| 期待値（EV） | シナリオの確率加重平均で表した、選択肢の生涯純価値（円換算・現在価値） |
| リソースプロファイル | 個人が登録する前提条件：投入可能な資金・月あたり時間・現在の収入・年齢/想定活動年数・リスク許容度 |
| 時間軸（ホライズン） | 選択肢の効果を見積もる年数。選択肢ごとに設定（例：資格=10年、投資=30年） |
| 探索 | 選択肢を並べて指標で比較し、確率・金額・期間などの前提をスライダーで動かして順位や損益分岐がどう変わるかを見る操作 |

## 4. 数理モデル（コア定義）

### 4.1 選択肢の期待値

各選択肢は3シナリオ（悲観 p1 / 中位 p2 / 楽観 p3、p1+p2+p3=1）で定義する。

```
シナリオ価値 = Σ[t=1..T] (年間効果額_t ÷ (1+r)^t) − 初期コスト − Σ(継続コストの現在価値)
EV = p1 × 悲観シナリオ価値 + p2 × 中位シナリオ価値 + p3 × 楽観シナリオ価値
```

- `T`：時間軸（年）
- `r`：割引率（デフォルト 2〜4%、設定で変更可）。遠い将来の効果を割り引いて現在価値に揃える
- `年間効果額`：収入増・支出減・資産リターンなど、円換算できる年次の効果
- 非金銭効果（健康・自由時間・満足度）は **「自分ならいくら払うか」で円換算して加算するか、別軸スコア（後述）として保持**

### 4.2 比較用の正規化指標

| 指標 | 式 | 意味 |
|---|---|---|
| EV（生涯・現在価値） | 上式 | 絶対額での比較 |
| 時間対効果 | EV ÷ 総投入時間(h) | 「その努力は時給いくらか」 |
| 資金対効果 | EV ÷ 総投入資金 | 投じた1円がいくらになるか |
| 最悪ケース | 悲観シナリオ価値 | 「外したとき何を失うか」。リスク許容度と照合 |
| 損益分岐確率 | EV=0 となる楽観/中位シナリオの確率 | 「どのくらい信じられれば張れるか」 |

### 4.3 判定

- **有望**：EV > 0、最悪ケースが許容損失の範囲内、リソース制約を満たす
- **条件付き**：EV > 0 だがリソースまたは許容損失に抵触 → 抵触内容を明示（「時間が月10h不足」等）
- **見送り**：EV ≤ 0、または損益分岐確率が非現実的に高い

## 5. リソースプロファイル（「個人のできる範囲」の定義）

最初に1回登録し、全選択肢の判定に自動適用する。

| 項目 | 型 | 例 | 使い方 |
|---|---|---|---|
| 投入可能資金（一時金） | 円 | 100万円 | 初期コストがこれを超える選択肢は「条件付き」 |
| 月あたり投入可能額 | 円/月 | 5万円 | 継続コストの上限 |
| 月あたり投入可能時間 | 時間/月 | 40h | 学習・副業系の実行可能性判定 |
| 年齢・想定活動年数 | 年 | 35歳 / あと30年 | 時間軸Tの上限。回収期間が活動年数を超える選択肢に警告 |
| 現在の年収・生活費 | 円 | — | 機会費用と「収入が途切れた場合の耐久月数」の計算に使用 |
| 許容損失 | 円 | 200万円 | 最悪ケースとの照合 |
| 割引率 | % | 3% | 現在価値計算に使用 |
| 併走可能数 | 個 | 2 | 同時に走らせられる選択肢の数（エネルギー制約の近似） |

## 6. 対象ドメイン（選択肢テンプレート）

選択肢は自由入力できるが、入力を助けるテンプレートを用意する。

| ドメイン | 例 | テンプレートが促す入力 |
|---|---|---|
| キャリア | 転職、昇進を狙う、業界を変える | 年収差分、移行期間、失敗時の戻りやすさ |
| 学習・スキル | 資格、学位、語学、プログラミング | 学習時間、費用、収入への反映率と反映までのラグ |
| 資産形成 | 積立投資の増額、住宅購入 vs 賃貸 | 利回りレンジ、期間、流動性 |
| 独立・事業 | 起業、フリーランス転向 | 立ち上げ期間の収入減、成功/存続確率、撤退コスト |
| 健康 | 運動習慣、治療、禁煙 | 医療費削減、活動年数への影響、QOL換算 |
| 生活基盤 | 移住、転居、車の保有 | 生活費差分、収入機会の変化、可逆性 |

> テンプレートには**日本の公的統計等に基づく参考レンジ**（例：転職による年収変動の分布）を注記として添えるが、数値の入力・判断は常にユーザー自身が行う。アプリは予測を断定しない。

## 7. 機能要件

### 7.1 MVP（v1）

1. **リソースプロファイル登録**：5章の項目を入力し localStorage に保存
2. **選択肢エディタ**：テンプレート選択 → 3シナリオ（確率・年間効果・期間・コスト）を入力 → EVと各指標を即時計算・内訳表示
3. **俯瞰ビュー（探索の中心）**：全選択肢を1画面で比較
   - 指標（EV / 時間対効果 / 資金対効果 / 最悪ケース）でソート
   - 判定バッジ（有望 / 条件付き＋理由 / 見送り）
   - **リスク×リターンの散布図**（横軸=最悪ケース、縦軸=EV）で「張れる場所」を視覚化
4. **感度スライダー**：確率・効果額・期間・割引率を動かすと全指標と順位がリアルタイムに変わる。損益分岐確率を常時表示
5. **組合せチェック**：選択した複数の選択肢の合計コストがリソース（資金・時間・併走可能数）に収まるかを判定
6. **保存・書き出し**：全データを localStorage 保存、JSONでエクスポート/インポート

### 7.2 将来（v2以降）

- 年次の振り返り入力（実際どうだったか）と見積もり精度の可視化
- モンテカルロ試算（3点シナリオを分布とみなした確率的シミュレーション）
- 非金銭軸（自由時間・健康・満足度）の多目的比較ビュー
- 選択肢間の依存関係（「Aを取るとBが不可能になる」）の表現

## 8. 非機能要件

- **静的HTML 1ファイル**、GitHub Pages 上で動作。サーバー・ビルド工程・外部API不要
- データはすべて localStorage とファイル入出力のみ。**外部送信しない**（人生設計データのため特に厳守）
- 依存ライブラリなし（Vanilla JS、散布図はSVG手描き）
- 日本語UI、スマホ幅対応、ライト/ダーク両対応（`color-scheme`）

## 10. 画面構成（1ページ内タブ）

1. **前提**：リソースプロファイル入力
2. **選択肢**：エディタ（テンプレート → シナリオ入力 → EV内訳）
3. **俯瞰**：比較テーブル＋リスク×リターン散布図＋組合せチェック
4. **感度**：1選択肢を選んでスライダー探索、損益分岐確率の表示

## 11. スコープ外（やらないこと）

- せどり・ポイ活・キャンペーン等の短期・少額案件の管理
- 投資助言・税務助言・法的助言にあたる断定的な推奨（数値はユーザー入力、アプリは計算と可視化のみ）
- 将来の自動予測（外部データ連携による自動見積もり）
- クラウド同期・複数ユーザー

## 12. 成功指標

- 選択肢1件をテンプレートから **5分以内** に入力してEVが出る
- 俯瞰ビューで**3つ以上の人生の選択肢が同じ物差し（円・現在価値）で並ぶ**
- 「条件付き」判定に必ず**どのリソースが足りないか**が表示される
- 前提を動かしたとき、**順位が入れ替わる境界（損益分岐）**が見える
