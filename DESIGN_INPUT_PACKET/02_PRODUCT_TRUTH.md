## WIN CONDITION

純資産 = 資金 + 台資産(購入価格×0.45の合計) − 借入残高 が **100,000,000 以上**(index.html:387, 676, 945)。
到達日数で S(65日以内) / A(85日以内) / B(120日以内) / C の評価が付く(:951)。
クリア後もゲームは終了せず継続できる(:1318 の文面および進行の継続)。

## LOSS CONDITION

営業日の処理後に資金が負で、かつ緊急融資枠(台資産×0.7+2,000,000)を超えて借りられない場合に倒産(:909-917, 1276, 1312)。
倒産後は `isDead()` により、やり直し以外の全操作が拒否される(:1276-1298, 1802-1838 の15箇所)。

## TIME MODEL

- **ターン制**: 1営業日 = 利用者の1操作(index.html:931, 1788-1800)
- 特日: 日付の数字に7を含む日(:678)
- 週末: `day % 7` が 6 または 0 の日(:679)
- 週次: `day % 7 === 0` で週次レポート(:955)、`day % 7 === 1` でブーム更新(:745)
- 実時間 / tick / 放置進行: **不在**。`setInterval` は試打の演出とオート回転のみ(:1443, 1567, 1636)

## RANDOMNESS

- 実装: `Math.random()` のみ。ヘルパ `rand(a,b)`(:624)
- **シード指定・再現性の仕組みは存在しない**(R-50)
- 用途と確率(コードから確認できる範囲):
  - 運イベント: 毎日50%で発生、80件から重み付き抽選(:540, 753-758)
  - 数値依存イベント: 条件成立+クールダウン経過の候補を各`p`(0.3〜1.0)で抽選し1件採用(:770-779)
  - 客数の揺らぎ: ×0.9〜1.1(一般)、×0.9〜1.05(常連)、×0.8〜1.2(プロ)(:820, 829, 832)
  - 客単価の揺らぎ: ×0.8〜1.2(:854)
  - 粗利率の揺らぎ: ±0.09(:855)
  - 台人気の劣化: decay×0.7〜1.3(:860)
  - 評判の揺らぎ: ±0.5(:906)
  - 行政指導: 警戒度8超で25%(:795)
  - 試打スロット: 設定補間した確率でBIG/REG、小役は固定確率(:1405-1416)
  - 試打パチンコ: 1/denom の当選、リーチ1/12、RUSH継続 rushPct(:1573-1574, 1609)
- 分布はいずれも一様乱数の直接比較・線形補間であり、正規分布等の加工は行われていない。
