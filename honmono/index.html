AIが「美女」を無限に作る時代、
いちばん希少なのは「本物の人間」です。

HONMONO は、AI生成コンテンツが溢れるインターネットで 「実在すること」を証明し、見分け、価値に変えるための無料ツール群です。 すべてブラウザ内で動作し、あなたのデータはどこにも送信されません。

ツール一覧

🔍

画像来歴チェッカー

画像をドロップすると、C2PA(コンテンツ来歴)・EXIF・XMP・生成AIツールの痕跡をその場で解析。 「この写真はAI生成か? カメラ撮影か?」の判定材料を提示します。

画像を調べる → 🪪

実在証明バッジ

クリエイター向け。「私はAIではなく実在の人間です」を相互リンク方式で証明するページとバッジを、 その場で生成してダウンロードできます。

バッジを作る → 🕵️

AIアカウント鑑定

SNS・マッチングアプリで出会ったアカウントが「AI製・なりすまし」でないかを、 チェックリストでリスク診断。ロマンス詐欺対策にも。

診断する → 🌟

「AI不使用・実在証明済み」を掲げるクリエイターのディレクトリ。 本物の人間に仕事を頼みたい企業・ファンのための検索台帳です。

なぜ作ったか

AI美女・AIインフルエンサーは誰でも量産できるため、市場は急速に飽和し、 同時に「見ているものが本物か分からない」という不信がインターネット全体に広がっています。 HONMONO はその逆張りです。AI生成が増えるほど価値が上がる 3 つの軸で設計しています。

① 証明する実在の人間・実写のコンテンツであることを、来歴データと相互リンクで示す(来歴チェッカー/実在証明バッジ)
② 見分けるAI製アカウント・なりすまし・詐欺を、誰でも使える道具で検知する(AIアカウント鑑定)
③ 束ねる「本物であること」を選んだクリエイターを可視化し、仕事とファンにつなぐ(実在クリエイター名鑑)

ロードマップ

  • Phase 1(現在) — 4ツールのMVP公開。全機能ブラウザ内完結・無料。
  • Phase 2 — C2PA電子署名のブラウザ内フル検証、証明ページのホスティング代行、名鑑の掲載審査フロー。
  • Phase 3 — マッチングアプリ・ファンコミュニティ向け検出API(B2B)、広告主向け「実在クリエイター」マッチング。
免責: 本ツール群の判定は「参考情報」です。メタデータは編集・削除が可能なため、 AI生成の痕跡がない=人間、痕跡がある=悪意、を断定するものではありません。 重要な判断には複数の証拠を組み合わせてください。
