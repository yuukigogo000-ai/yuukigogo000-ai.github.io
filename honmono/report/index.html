「このモデルはAI画像を見分けられます」と言うだけなら誰でもできます。 このページは、実際に測った数字と、外れた場面を全部出すためのものです。都合の悪い数字も消していません。

1. 結論

  • 公開されているAI画像判定モデルは、ほとんど使い物にならない。 同一条件で9本を測り、8本は実写を10〜88%の割合でAIと誤判定した。「AI画像を検出する」より「実在の人を偽物扱いする」ほうが実害が大きいため、この誤判定率では搭載できない
  • 唯一まともだった1本はライセンスが未記載で、商用利用の可否が判断できず採用を見送った(作者は13か月無応答)
  • そこで自分で学習した。学習データは商用利用が明示的に許諾されたものだけを使い、条件が不明・非商用・研究目的限定の22データセットは除外した
  • 結果、外部545枚で 実写の誤判定 1.8% / AI検出 70.0%。人物の顔だけを別に測った615枚では 誤判定 1.1% / 検出 92.2%
  • それでも「AIではない」ことの証明には使えない。 2025年世代の生成器は4割近く見逃す

5. 弱点(正直に書く)

  • 2025年世代の生成器は4割近く見逃します(検出 62.6%)。Seedream 4・Gemini 2.5・FLUX Pro 等。生成器は毎月新しくなるので、この数字は放っておけば下がり続けます
  • 古いGAN風に正方形で切り取られた顔では、実在の人の誤判定が 5.0% まで上がります(通常の写真では 1.8%)
  • 「AIではない」ことの証明には使えません。 検出しなかった=人間、ではありません
  • 正方形に切り取った実写では誤判定が 1.8% → 2.9% に上がることを、意図的な加工テスト(切り抜き・低画質JPEG・縮小・白黒化)で確認しています
  • この数字は私たち自身が測ったものです。第三者による再測定は行われていません。だからこそ手順を下に公開しています

7. 再現方法

この数字を疑う場合、次の手順で確かめられます。手元にモデルを落として自分のデータで測るのがいちばん早いです。

  1. 来歴チェッカーを開くと honmono_v31_int8.onnx.part1 / .part2 が読み込まれます。2つを順に結合すると 90MB の ONNX ファイルになります
  2. 入力は 256×256・RGB・ImageNet 正規化。出力は2クラス(実写 / AI)の logit。しきい値は 0.8
  3. 評価セットは公開データセット4本から作っています(上表の mj6 / tellif / eddy / faces)。データセット名を明記しているのは、同じものを自分で組み直せるようにするためです
  4. ブラウザ実装が Python と同じ結果を出すことは、80枚で照合して確認しています

評価手順の詳細と生ログは AI_DETECTOR_EVAL.md にあります。 モデルの利用条件は モデルライセンス をご確認ください。

8. 訂正の履歴

2026-08-18 — v2 の数値には、評価データを覗いてしまった疑いがあります。
v2 を学習したとき、途中経過の良し悪しを判定する「選択用データ」に open-image-preferences-v1 を使っていました。 その後の汚染チェックで、このデータセットの画像が評価セット eddy の AI 画像と完全一致(ハッシュ距離0)していることが分かりました。 画像6組を目視で並べて確認済みです。つまり v2 は「どの途中経過を採用するか」を決める段で、評価に使うはずの画像を見ていたことになります。 v3 以降はこのデータセットを学習にも選択にも使わず、選択用は評価4セットに出てこない生成器(xAI Aurora)に差し替えました。 v2 の公開数値は、この分だけ良く出ていた可能性があります。

同じことが起きないように、収集したデータと評価セットを全件ハッシュ照合する検査器を作り、 さらに「わざと同じ画像を仕込んで、本当に見つけられるか」を確かめてから使っています(仕込んだ6枚を6枚とも検出・無関係な30枚の誤検出0)。
