1. このソフトの目的

生成AIによる「実在しない美男美女」のアカウント・コンテンツは、誰でも量産できるため急速に増え続けています。 その結果、次の3つの問題が起きています。

  • 消費者の被害 — なりすまし・ロマンス詐欺・偽アカウントへの課金
  • クリエイターの埋没 — 実在の活動者がAI量産アカウントに埋もれ、疑われる
  • 信頼の崩壊 — 「見ているものが本物か分からない」不信の常態化

HONMONOは、AI美女ビジネスと同じ土俵で競うのではなく、「実在すること」自体を検証可能な価値に変えることでこの問題に対抗するツール群です。 AI生成コンテンツが増えるほど、本物の証明の価値は上がる——その構造を利用しています。

全ツールは無料・登録不要・完全ブラウザ内動作(入力データはどこにも送信されません)。

3. 画像来歴チェッカーの使い方

  1. 調べたい画像(JPEG / PNG / WebP / HEIC / AVIF)または動画(MP4 / MOV)を用意します。できるだけ「元データ」に近いものが有効です(SNSの再保存やスクリーンショットはメタデータが消えています)
  2. ページの点線枠に画像をドロップ、またはクリックして選択します
  3. 数秒で判定バナーが表示されます(下表参照)
  4. 「検出されたシグナル」と「抽出メタデータ」で根拠を確認します
  5. C2PA来歴があれば「C2PA署名の検証」欄で署名の真正性(改ざんの有無)が自動検証されます
  6. メタデータが消されていた場合は「次の一手」の逆画像検索ボタンで盗用元・使い回しを探せます
判定意味
🤖 AI生成の痕跡があります生成AIツールの記録・国際規格(IPTC)のAI申告・生成パラメータ等が画像内に見つかった
📜 コンテンツ来歴(C2PA)付き編集履歴の来歴データが埋め込まれている。署名の真正性はページ内の「C2PA署名の検証」で自動チェックされる
📷 カメラ撮影の痕跡がありますカメラ機種・撮影日時などのEXIFが残っている(実写の可能性を高める材料)
🗂️ ストック素材サイト由来Adobe Stock 等の素材サイトの痕跡がある。SNSの「本人写真」としては不自然で、流用または架空人物の疑い
🟡 AI生成を疑う手がかり(弱)決定的な証拠はないが、生成AI定番サイズなど注意すべき特徴がある
❓ 判定材料がありませんメタデータなし。「AIではない」という意味ではない点に注意

検出対象: C2PA来歴(署名検証つき)/ IPTC digitalSourceType(AI申告)/ Stable Diffusion・ComfyUI・NovelAI・Midjourney・DALL·E・Firefly・Sora・Kling など30種超のAIツール痕跡 / カメラEXIF / XMP / JPEGコメント。 素材サイトのタイトル・キーワードにある「Generative AI」等の表記や、Adobe Stock・Shutterstock 等ストック素材サイトの痕跡も検出します。さらにメタデータが消されている場合も、再圧縮品質・プログレッシブ形式・AI定番サイズ・EXIFサムネイルとの不一致などから 「このファイルがどんな経緯をたどったか」を推定して提示します。署名検証はC2PA公式のオープンソースSDK(WASM)を同梱しており、外部送信なしで完結します。

4. 実在証明バッジの使い方

対象: 「実在する人間である」ことを差別化にしたいクリエイター(イラストレーター・モデル・コスプレイヤー・配信者など)。

  1. フォームに活動名・SNSリンク(2つ以上推奨)・実在宣言を入力し、「生成する」を押します
  2. プレビューを確認し、証明ページ(honmono-proof.html)をダウンロードします
  3. 証明ページを自分の管理下のURL(自分のサイト・GitHub Pages等)で公開します
  4. 最重要: 入力した全SNSのプロフィール(bio)に、公開した証明ページのURLを記載します。これで「SNS ⇄ 証明ページ」の相互リンクの輪が完成します
  5. バッジ(HTML / Markdown)をサイトやREADMEに設置します。リンク先は公開済みの証明ページURLです

なぜ偽造できない? なりすまし犯は他人のSNSプロフィールを書き換えられないため、「証明ページ → SNS」のリンクは作れても「SNS → 証明ページ」の逆リンクを作れません。輪が閉じていることが本人性の証明になります(Keybase等で実績のある方式)。

5. AIアカウント鑑定の使い方

  1. 調べたいアカウントの投稿・プロフィール・DMでのやり取りを思い浮かべながら、当てはまる項目にチェックを入れます
  2. 画面下部にリスクスコア(0〜100)と判定(低・中・高)がリアルタイムで表示されます
  3. 「信頼シグナル」(ビデオ通話で確認した等)に該当があればチェック — スコアが減点されます
  4. 「診断結果をコピー」で共有用テキストを、「結果画像を保存」でSNS等に貼れる結果カード画像(PNG)を出力できます
スコア判定推奨アクション
0〜19低強い危険信号なし。ただし金銭の話が出たら即再評価
20〜44中ビデオ通話・逆画像検索・来歴チェッカーで検証を。金銭・個人情報は渡さない
45〜100高典型的特徴に多数一致。ブロック・通報を検討。被害時は警察相談 #9110

「逆画像検索で別人がヒット」「金銭・投資への誘導」などの決定的シグナルは、1つでスコア40以上、2つで65以上になるよう下限が設定されています。

6. 実在クリエイター名鑑の使い方

探す側: キーワード検索・ジャンルボタンで絞り込み、各カードの「証明ページ」リンクから相互リンクの輪を自分の目で検証できます。

載りたい側:

  1. 実在証明バッジで証明ページを作成・公開し、SNSとの相互リンクを完成させます
  2. 名鑑ページの「掲載申請フォーム(GitHub Issue)」から、活動名・ジャンル・証明ページURL・紹介文を送ります
  3. 運営が相互リンクの輪を確認後、名鑑に掲載されます(無料)

7. よくある質問

「判定材料がありません」と出たら、その画像は本物?
いいえ。SNS・メッセージアプリ・スクリーンショットを経由するとメタデータはほぼ確実に消えます。判定不能=中立です。可能なら投稿前の元データを入手して再チェックしてください。
「カメラ撮影の痕跡あり」なら実写と断定できる?
断定はできません。EXIFは専用ツールで偽装可能です。あくまで「実写の可能性を高める材料の1つ」として、他の証拠(ライブ配信・相互リンク証明など)と組み合わせてください。
AIで作った画像なのに「痕跡なし」になった。バグ?
バグではありません。メタデータを削除してから配布されたAI画像は、メタデータ検査では検出できません(これはあらゆる検査ツール共通の限界です)。そこで、画素そのものからAIらしさを推定する自前学習モデル(HONMONO v2)を「🧪実験: 画素からのAI判定(参考値)」として搭載しました(2026-08-18)。学習に使っていない外部545枚での実測は、実写をAIと誤判定 2.2%・AI画像の検出 62%・AUC 0.93。ただし2025年世代の生成器(Seedream 4・Gemini 2.5・FLUX Pro 等)は半分以上見逃すので、「AIではない」証明には使えません。公開されている判定モデル9本も実測しましたが、8本は実写を10〜88%の割合でAIと誤判定するため不採用でした。評価の詳細は 実測レポート を公開しています。
画像をアップロードして大丈夫?
画像はサーバーに送信されません。解析はすべてあなたのブラウザの中で行われ、ページを閉じれば何も残りません(オフラインでも動作します)。
鑑定スコアが「高」だったら、その人は偽物?
断定ではなく「典型的な特徴への一致度」です。実在の人でも当てはまる項目はあります。ただし金銭・投資の話が出ている場合は、スコアに関係なく詐欺を最優先で疑ってください。
実在証明バッジは審査があるの?
バッジ生成自体は誰でも可能で、審査はありません。証明力は「相互リンクの輪が実際に閉じているか」で決まり、見る人が検証できます。名鑑への掲載時のみ、運営が輪の完成を確認します。

8. 制限事項と免責

  • 本ツール群の出力はすべて参考情報であり、真正性・実在性を法的に保証するものではありません
  • メタデータは追加・編集・削除が可能です。「痕跡なし」は人間の証明にならず、「カメラ情報あり」も偽装可能です
  • C2PAの署名検証は「改ざんの有無」を確認するものです。署名発行者が信頼できる組織かどうかの照合(トラストリスト)は行っていません。発行者名は表示されるので、内容はご自身で判断してください。公式ツールとの併用も有効です
  • 対応形式は画像 JPEG / PNG / WebP / HEIC / AVIF、動画 MP4 / MOV です。HEIC/AVIFはメタデータ走査のみで、ブラウザによってはプレビューが表示されません
  • 「経緯の推定」「AI定番サイズ」「サムネイル不一致」は弱い手がかりであり、単独でAI・改ざんを断定するものではありません
  • 本ツールの利用により生じたいかなる損害についても、運営者は責任を負いません
  • 虚偽の実在宣言・他人になりすました証明ページの作成は、信用毀損・詐欺等の法的責任を問われる可能性があります

9. プライバシー

  • 画像・フォーム入力・チェック内容は、一切サーバーに送信されません。全処理がブラウザ内で完結します
  • 本サイトは独自のCookie・トラッキング・アクセス解析を使用していません(ホスティングのGitHub Pagesが標準的なアクセスログを記録します)
