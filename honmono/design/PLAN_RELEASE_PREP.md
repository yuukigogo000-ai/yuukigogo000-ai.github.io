# 公開前 最終整備 計画書(機能・法律・収益化)

作成 2026-08-20 / 工程1(設計書) / 対象 HONMONO 全体

この計画は「UI改善(工程5)に入る前に、中身・法務・収益化の土台を確定させる」ためのもの。
**原則: いま確定させるのは内容・構造・文言であって、見た目ではない。**

## 3. B. 法律対策

### B群-1: いま既に違反・虚偽になっているもの(最優先)

| ID | 項目 | 現状 | 対処 |
|---|---|---|---|
| B1 | 同梱ライブラリのライセンス表示 | c2pa-js(Adobe・MIT)、onnxruntime-web(Microsoft・MIT)を**著作権表示なしで再配布中** | 各 LICENSE を同梱し、サイトに謝辞・ライセンス欄を作る |
| B2 | 学習データの帰属表示 | Open Images(CC BY 2.0)、Rapidata(CDLA-Permissive-2.0)は帰属表示が条件。`design/dataset_licenses.json` にはあるが**利用者から見える場所に無い** | 帰属を明示するページを作り、モデルの説明から必ずリンクする |
| B3 | 全部免責の条項 | 「本ツールの利用により生じたいかなる損害についても、運営者は責任を負いません」= 消費者契約法8条により**その条項自体が無効**。無効な条項に頼っている状態は、有効な限定より弱い | 「故意または重大な過失による場合を除き」に限定する |
| B4 | 「なぜ偽造できない?」 | 断定。相互リンクはSNSアカウント乗っ取りで破れる | 「偽造が難しい理由」に変更し、破れる条件を明記 |
| B5 | 「オフラインでも動作します」 | Service Worker が無いので**事実に反する**。チェッカー自身は逆のことを表示している | 記述を訂正 |
| B7 | 名鑑の架空クリエイター | 「実在」を売る製品が架空の人物4名を掲載。ラベルは付いているが、注意書きがカードより**下**にある | 架空の人名をやめ、構造だけを示すテンプレートカードに差し替え、注意書きを上に移す |

### B群-2: 課金を始める前に必要なもの

| ID | 項目 | 判断 |
|---|---|---|
| B6 | プライバシーポリシー・利用規約の独立ページ | 現在は説明書の中の1節のみ。**文面は今つくる**(法務文書は内容が本体で、見た目の影響が小さい) |
| B8 | ホスティング移転 | **Cloudflare Pages + R2**。理由: Pages は商用利用可・帯域無制限、R2 はエグレス無料でモデル90MBを捌ける。Vercel Hobby は商用禁止、Netlify 無料は100GB/月でGitHubと同じ天井 |
| B9 | 特商法表記 | **B2Bのみなら不要**(F4)。消費者向けに課金した瞬間に必要になり、そのとき自宅住所の公開かバーチャルオフィス契約を迫られる。→ **消費者課金を後回しにする強い理由** |
| B10 | インボイス登録 | 経過措置80%が2026-09-30で終了(F5)。法人が買い手なら、免税事業者のままだと相手の税負担が増える。**初回B2B商談の前に判断** |
| B11 | 商標 | 「HONMONO」は一般名詞に近く、他社の先行登録がありうる。J-PlatPat で第9類・第42類を調査。**改名コストが最小なのは今** |

## 4. C. 収益化施策

**方針(前回合意):** 無料ツールは収益源ではなく実力の証明書と集客装置。**金は企業から取る。**

| ID | 施策 | 内容 | 実行 |
|---|---|---|---|
| C1 | **B2B: 判定モデルのライセンス供与** | 買い切り30〜100万円/年間契約 月5〜20万円/API従量/導入支援。売るのは「重み+推論コード+実測レポート+更新の約束+書面ライセンス」 | `/business/` を作る |
| C2 | 実測レポートの再現可能化 | 「自分で作ったモデルを自分で測った数字」への当然の反論に耐えるため、評価手順・評価セットの出所・スクリプトを公開する | `/report/` + リポジトリ |
| C3 | 支援リンク(GitHub Sponsors) | GitHub Pages の規約上でも許可されている(F1)。**いま設置できる唯一の収益導線** | ユーザーが Sponsors を有効化 → Claude が導線を置く |
| C4 | 消費者向け有料レポート | **Phase 1では作らない**(破壊的検証 D5 の結論) | 見送り |

### 価格の出し方
公開するのは**レンジと考え方**まで。確定価格は出さない(案件ごとに条件が違い、先に数字を出すと交渉余地が消える)。

## 5. 破壊的検証(この計画を壊しにいった結果)

計画を書いたあと、意図的に反証を試みた。**7件が生き残り、うち3件が計画を変更させた。**

| # | 攻撃 | 検証結果 | 判定 |
|---|---|---|---|
| D1 | 「無料ツールが集客装置」と言うが、**人が来ているのか誰も知らない**。アクセス解析が無い | 実測: 計測コードは1行も無い。GitHub Pages のアクセスログは利用者から見えない | **成立**。収益化の前に A6(Cookieレスの計測)が要る。計画に追加した |
| D2 | **B2Bの買い手はこのサイトを見に来ない**。法人向けページを作っても、押し出す手段が無ければ収益ゼロ | 反論不能。ページは「問い合わせが来たとき恥をかかない」ための受け皿にすぎない | **成立**。ただし受け皿が無ければ商談は始まらないので作る。**押し出しはユーザーの行動であり、私の実装範囲外である点を明記** |
| D3 | **売り物を無料で全世界に配っている**。90MBのONNXは誰でもダウンロードして再配布できる。無料で手に入るものに法人が金を払うか | 一部成立。ただし法人が買うのは「重み」ではなく**法務が通るライセンスと、新しい生成器への追随**。現に公開モデル9本中8本が実用不可で、唯一使える1本はライセンス未記載で採用できなかった——これは我々自身が実測で確かめた事実 | **一部成立**。配布は続ける(出し惜しみは思想に反する)。ただし**A5(ライセンス明示)が必須**。無表示のまま配ると「自由に商用利用可」と読まれ、売り物が消える |
| D4 | 移転先の Cloudflare Pages は**1ファイル25MiB上限**。現行の70MBパートは載らず、移転した瞬間に画素判定が壊れる | 一次情報で確認、そのとおり | **成立**。移転計画をPages+**R2**に修正した(F2/F3)。R2はエグレス無料なので帯域問題も同時に解ける |
| D5 | 消費者向け「検証レポート1,000円」の需要は本当にあるか。疑われた人はスクショで済ませる。しかも決済導入には**特商法=自宅住所の公開**が付いてくる | 需要の証拠は無い。一方コスト(決済・住所・規約・返品条項)は確実に発生する。B2Bなら特商法は適用除外(F4) | **成立**。**C4を計画から削除した**(Phase 1では作らない)。これが破壊的検証の最大の成果 |
| D6 | 「学習データは商用利用可のものだけ」は本当か。Unsplash / Pexels は AI学習を禁じていないか | 両ライセンスの原文を確認。商用利用可、AI学習・データセット化を禁じる条項は**無い**。Unsplashの禁止事項は「大幅な改変なしの販売」と「競合する写真サービスの複製」、Pexelsは「未改変コピーの販売」「他のストックサイトでの再配布」等。いずれも本件に当たらない | **不成立**。主張は維持できる |
| D7 | 名鑑に**架空の人物**を並べている。AIが偽の人間を作ることに対抗する製品が、自分で偽の人間を作って飾っている | ラベルは付いているが、注意書きはカードより下にある。ラベルの有無に関わらず、この製品でこれをやる意味が無い | **成立**。B7として、人名をやめ構造だけのテンプレートカードに差し替える |
| D8 | 「すべてブラウザ内で完結・外部送信なし」は誇張ではないか | 画像・入力データについては真。ただしバッジのMarkdown版は shields.io(外部)を使い、モデル90MBはGitHubから取得する(=IPアドレスは渡る) | **一部成立**。プライバシーポリシーで正確に書き分ける(B6に含める) |
| D9 | 免責を「重過失を除き」に限定すると、かえって責任を負う場面が増えるのでは | 逆。現在の全部免責は消費者契約法8条により**条項ごと無効**なので、いま何の保護も無い。限定すれば軽過失分は有効に免責される | **不成立**(修正は正しい) |
| D10 | いま `/business/` を作ると工程5のUI刷新で作り直しになる。二度手間では | 一部成立。だが法人向けページの価値は文章と数字であり、`honmono.css` に載せる限り作り直しは軽い。中身が無いまま工程5に入るほうが高くつく | **不成立**。ただし**装飾は作り込まない**方針を明記 |

### 破壊的検証で変わったこと(3点)
1. **C4(消費者向け有料レポート)を削除** — 需要の証拠が無く、特商法による住所公開のコストが確実に上回る(D5)
2. **移転先を Cloudflare Pages 単体 → Pages + R2 に修正** — 25MiB上限でモデルが載らないため(D4)
3. **A6(アクセス計測)を追加** — 集客装置と言いながら来訪者数を知らないままだった(D1)

## 7. この計画が守る前提

- 人物・顔を描いたAI生成画像は資材に一切使わない(自己矛盾)
- バッジ・名鑑への掲載を有料にしない(信用を売ることになる)
- 精度を有料版で出し惜しみしない(実在の人を守る道具を金で差別化しない)
- 広告を貼らない(中立な検証の看板と両立しない)
