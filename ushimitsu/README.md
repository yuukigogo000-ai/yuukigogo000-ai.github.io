# うしみつ時計

時計の針を自分で回して、夜明けまで生きのびる札バトル。1 回 10〜15 分。見た目は仮(灰色の箱の段階)。

**ひとことで言うと:** 針を回したぶんだけ強く打てる。けれど針が印を越えると、化け物が動く。

これまでに作ったもの(おはじき・ペンギンずもう = 盤の上で押し合う / けもの天下 = 地図を取り合う)とは別の遊びにするため、
盤も位置も無くし、「時間の切り分け」だけを遊びの中心にした。

## 決まり

- 行動は「何をするか」と「針を何刻回すか」で決める。回した刻だけ時間が進む
- **攻めは、回し終わった刻に当たる。** 長く回すほど 1 刻あたりが強い(打つ: 1 刻 3 / 2 刻 7 / 3 刻 12)。同じ刻なら、あなたが先
- **守りは、回しているあいだだけ効く。** 次の行動には残らない
- 化け物の次の行動は、時計のまわりに印として必ず見えている。針がその刻に来ると動く
- 金色の輪の印は大技。「かまえ」の数だけ先に削ると、つぶせる(2 刻ひるむ)
- 「打つ」「受ける」はいつでも使える。札は 2 刻ごとに 1 枚引く(手札 3 枚まで)
- 針がてっぺん(鐘)を過ぎるたび、化け物の攻撃が 2 上がる(長引かせても得をしない)
- 体力が 3 割以下で、守りが 1.5 倍(火事場)
- 一夜は 9 つの刻。どの刻に何がいるかは、夜の始めに全部見える。最後は丑三つ時
- 丑三つ時は、相手を倒す(結末「退治」)か、夜明けの刻まで立っていれば(結末「夜明け」)勝ち

## 調査のどこを使ったか

| 調査で分かったこと(`../reports/`) | このゲームでの形 |
|---|---|
| 評価が高い戦闘は、入力の回数でなく 1 回の判断の重さを設計している | 1 手 = 行動 × 刻 × 相手。押すボタンは少ないが、毎手「あと 1 刻回すか」で迷う |
| 敵の行動予告は、調査で最も裏付けが強い | すべての行動が、時計の上に刻と数字つきで見えている |
| 大技を直前につぶす仕組み(グランディア・オクトパス型)は一貫して好評 | かまえ。「間に合うか」を刻で数える |
| 運で負けると理不尽に感じる | 戦いの中の運は、札の引きだけ。行動の結果は出す前に画面に出て、その通りになる |
| 手札事故(使える札がない)は定番の不満 | 「打つ」「受ける」は札ではなく、いつでも使える |
| 消化試合と引きのばしは嫌われる | 鐘(長引くと相手が強くなる)。丑三つ時は夜明けで決着 |
| 自分のせいでない即死は嫌われる | 捨て身・出来事では倒れない。倒れる手は、出す前に「これをやると倒れる」と出る |
| 隠れた補正は恨まれ、見える決まりは受け入れられる | 火事場と鐘は、あそびかたに書いてある同じ決まり |
| ボスは別物にする。ただし事前に見せる | 丑三つ時の相手 3 種は、それぞれ決まりを 1 つ変える。だれが来るかは夜の始めに分かる |
| 先が見える地図と、少数の重い選択 | 9 つの刻。分かれ道は 5 回、どれも 2 択 |
| 出来事は、数を増やすほど良くなる | 2 択の出来事 9 つ(文は `src/tales.js` にまとめてあり、物語工房などで差し替えやすい) |

## 中身

夜回り 3 人(打つが強い / 崩すと得をする / やけどで弱らせる)、札 29 種(きたえると強くなる)、おまもり 16 種、
化け物 20 種(ふつう 10・手ごわい 3・真夜中の主 2 と手下・丑三つ時 3 と手下)、出来事 9 つ、結末 3 つ。
「きょうの夜」は日付で決まる同じ夜。途中の遊びは端末に保存され、続きから遊べる。通信なしでも開ける。

## ファイル

| ファイル | 中身 |
|---|---|
| `src/data.js` | 札・おまもり・化け物・夜回りの表 |
| `src/battle.js` | 戦いの決まり。依存は data.js だけ。乱数は盤面の中の種だけ |
| `src/run.js` | 一夜の進行(道・ごほうび・店・茶屋・出来事) |
| `src/tales.js` | 文章だけの表(刻ごとの一言・始まり・結末・出来事) |
| `src/bot.js` | 模擬の打ち手(検査と集計用。画面には入らない) |
| `src/ui.js` + `src/page.html` | 画面と入力(見た目は仮) |
| `build.mjs` | 1 ファイルに組み立てる → `index.html` と `artifact.html` |
| `test.mjs` | 検査。`node test.mjs --mutate` |
| `balance.mjs` | 強さの集計。`node balance.mjs [回数]` |
| `browser-check.mjs` | 実ブラウザでの通しプレイとオフライン確認。`NODE_PATH=$(npm root -g) node browser-check.mjs` |

## 確かめたこと(2026-11-15)

- `node test.mjs --mutate`: 81 件合格。同じ刻ならあなたが先、守りは回しているあいだだけ、かまえ崩し、おまもり 13 種、
  見通しと実際の一致、120 回の通しプレイが必ず決着すること、途中で保存して読み直しても同じ結果になることを含む。
- `node balance.mjs 150`(模擬の打ち手。各 150 回、3 人を順に使う)の勝率:

| 打ち手 | やさしい | ふつう | むずかしい |
|---|---|---|---|
| 2 手先まで読む | 89% | 72% | 50% |
| 1 手だけ読む | 69% | 45% | 23% |
| 上位 3 つから適当に選び、2 割はでたらめ | 35% | 19% | 9% |
| 「打つ」「受ける」だけ(札を使わない) | 34% | 15% | 3% |
| 1 刻ずつ受けるだけ | 0% | 0% | 0% |

  勝ちのうち「退治」と「夜明け」はおよそ半々。倒れる場所は、真夜中の主(5 つめ)と丑三つ時(9 つめ)に集まっている。
- 実ブラウザ(360×800 / 390×844、3 人、3 つの難しさ): タイトルから結末まで通しで動き、エラーなし、はみ出しなし。
  針を指で引っぱって刻を決める操作、行動の再生、店・茶屋・出来事・もちもの、オフラインでの再読み込みと続きからの再開も確認。

## 分かっていないこと

- **人が遊んで面白いか。** 数字は模擬の打ち手のもの。「見通しが全部出る」ので、考える楽しさになるか、ただの計算になるかは触らないと分からない
- 人の強さが、上の表のどの打ち手に近いか。1 手読みで「ふつう」45% なので、最初は難しく感じるかもしれない
- 針を引っぱる操作が、実機の指で気持ちいいか(検査はマウスの動きで代用)。± ボタンでも同じことができる
- 札 29 種・おまもり 16 種の強さのばらつきは、個別には見ていない(「やけど」は一度弱めた)
- 行動の再生の速さ(1 刻 0.19 秒)がちょうどいいか。再生中に時計をタップすると飛ばせる
- iPhone(Safari)での動作
