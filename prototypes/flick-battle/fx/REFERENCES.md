# はじきバトル 演出の見本集め(PC で動画と画面を見て、秒と音に置き換える作業表)

出どころ: `reports/はじきバトル演出の見本帳.md` の「見本集め」の章。ここは**記録用**の表で、空欄を埋めていく。
埋めた数字は `fx/tokens.js` の該当する値(各行の「反映先」)に入れ、根拠の印を「弱」から「実測」に変える。

## 決まり

- 見本の動画・画像は**リポジトリに入れない**(他社の画像を持ち込まない)。数字・所見・見た場所(動画の題名と時刻)だけを書く
- 演出の格は本物の結果で決める。見本にあっても、期待させて外す・結果より良く見せる・止められない演出は借りない(R2「借りない」の表)
- 優先 A の 18 件から。1 回の作業で「5 作品 × 3 場面」くらいが目安(R2・ヘブバンの運用からの推論)

## 測り方

1. 60fps の動画(公式のプレイ動画・トレーラー・自分の録画)を、コマ送りできる再生ソフトで開く(例: mpv は `.` で 1 コマ進む、VLC は `E`)
2. 「入力した瞬間」と「変化が始まった・終わった瞬間」のコマ番号を書き、差 × 16.7ms で秒にする
3. どの作品でも共通に見る 5 つ: 結果が出る何秒前に何が変わるか / 格の違いを色・大きさ・速さ・音のどれで表すか / 外れたときの画面は静かか / 回数の節目で何が起きるか / 最上位の演出が普段とどれだけ違うか
4. UI の画面ではさらに: 画面の下 1/3 に何が置かれているか / 文字の段の数と大きな数の略し方 / 結果の出る順と各段の秒 / ボタンの数と押したときの沈み / 説明が出る位置
5. 画面写真の見本は Game UI Database(gameuidatabase.com、無料)で作品名から探し、画面の種類や HUD の要素で絞る
