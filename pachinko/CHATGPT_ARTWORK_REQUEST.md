| 項目 | 指定 |
|---|---|
| 用途 | ホーム画面上部の「見せ場」。店の格と熱気を1枚で伝える背景アート |
| 出力形式 | JPEG(写実寄り)または PNG。最終的に幅1600px前後・250KB以下へ再エンコードする |

### 画づくり

- **シーン**: 営業中の大型パチンコ・スロットホールの内部。中央通路が奥へ伸び、
  左右に台の島が並ぶ。奥に光源(照明の集まり)があり、通路が明るく抜ける。
- **時間帯/照明**: 夜。天井照明と台の演出光による暖色(琥珀〜金)主体のライティング。
  奥から手前に向かって減光し、手前は影に沈む。
- **カメラ**: 目線高さよりわずかに高い位置から、通路の中心を捉えた1点透視。
  焦点距離は広角寄り(28〜35mm相当)。水平線は画面中央よりやや上。
- **人物**: 逆光のシルエットのみ。顔・服装のディテールは不要。10〜25人程度。
  台に座る人と通路を歩く人が混在し、「賑わっているが混雑しすぎていない」状態。
- **空気**: 軽いヘイズ(光条)とわずかな床の反射。過度なブルームは不可。
- **色**: ダーク(ほぼ黒)の地に、金・琥珀・温かいオレンジ。
  アクセントとして深い赤と冷たい青を各1〜2箇所まで。
  **虹色のネオンを全面に散らすことは禁止**(トーンが壊れる)。
- **質感**: 落ち着いた映画的なグレーディング。ノイズは最小。過度なHDR/彩度は不可。

### 含めてはいけないもの(MUST NOT CONTAIN)

- 文字・ロゴ・数字・UI要素(看板の文字、台の機種名、ボタン、メーター等を**一切**描かない)
- 実在するメーカー名・機種名・キャラクター・実在の店舗が特定できる意匠
- 人物の顔の識別可能な描写
- 現金・紙幣・賭博の勝利を煽る表現
- 画面の四隅を塞ぐ大きな前景オブジェクト(トリミングで破綻するため)
- 透かし・署名・枠線

### ネガティブ空間

中央通路(横幅の中央35%)は**奥へ抜ける明るい空間**として空けること。
ここに情報チップやテキストが重なっても読めるよう、
下部28%は輝度を落とし、細かいディテールを置かない。

## 受け取り後の組み込み手順(実装側の作業)

1. 画像を `pachinko/art/hall-overview.jpg` として配置する。
2. `index.html` の `buildStageArt()` 呼び出し箇所(起動時の1行)を
   `<img src="./art/hall-overview.jpg" alt="">` の挿入に差し替える。
   プレースホルダ関数は削除せず、画像が読めない場合のフォールバックとして残す。
3. `sw.js` の `PRECACHE` に `"./art/hall-overview.jpg"` を追加し、`CACHE` を次の世代へ上げる。
4. 360 / 390 / 430 / 1080 で再撮影し、セーフ領域の重なりを確認する。

外部CDN・Webフォント・実行時の外部取得は使用できないため、
**画像はリポジトリ同梱の静的ファイルとしてのみ受け入れられる。**
