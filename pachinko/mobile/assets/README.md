# App icon source

The owner selected neon-hall concept 8 on 2026-10-04. `icon-neon-source.png` is the unmodified generated artwork (1254×1254, RGB). It contains no lettering, third-party logos or user photograph.

Run `python scripts/package-icons.py` from the mobile directory to package the original artwork into the iOS 1024px icon, Android density/adaptive/round icons, PWA icons and existing native splash canvases. Pillow is required. No AI regeneration or network is performed by this command. `--check` verifies the packaged pixels and the output manifest without writing files.

`icon-neon-manifest.json` records the source and output hashes. Keep the source in the repository; do not replace it with a compressed chat screenshot.
