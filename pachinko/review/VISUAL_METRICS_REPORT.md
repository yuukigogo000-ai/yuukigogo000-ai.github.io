# VISUAL METRICS REPORT(客観ガードレール)

`VISUAL_METRICS_BASELINE.json` の指標群を自前実装で再計算し、
**同一の計測実装で Target と実装を比較**した(絶対値ではなく比率で判定するため)。

計測: 幅512pxへ正規化 → 輝度エントロピー / 勾配>0.10のエッジ比 / 暗部比(L<0.18) /
金相当色比(H25–65°, S>0.30, L>0.16) / 彩度比(S>0.35) / 輝度標準偏差 / 16px タイルの平坦率。

## 実装(screens/01-home-390.jpg)

| 指標 | 値 | 閾値 | 判定 |
|---|---|---|---|
| entropy | 6.4995 | ≥ 5.7100 (×0.88) | PASS |
| edge_ratio | 0.2340 | ≥ 0.2740 (×0.72) | **FAIL** |
| gold_ratio | 0.1160 | ≥ 0.0601 (×0.55) | PASS |
| saturated_ratio | 0.2503 | ≥ 0.1781 (×0.55) | PASS |
| luminance_sd | 0.1811 | ≥ 0.1269 (×0.72) | PASS |
| blank_tile_ratio | 0.1961 | ≤ 0.0699 (×1.75) | **FAIL** |
| (参考) dark_ratio | 0.7536 | Target 0.7533 | 一致 |

**4/6 PASS → 客観ガードレールも FAIL。**

未達2項目はいずれも「細かい情報密度」を測る指標であり、
Targetが写真的テクスチャと多数のテキスト要素で全面を埋めているのに対し、
実装はホール画の暗部と面の平坦さが残る。
ベースラインの注記(「指標を満たすためだけにノイズを増やしてはならない」)に従い、
数値合わせのための人工ノイズ増量は行っていない。
