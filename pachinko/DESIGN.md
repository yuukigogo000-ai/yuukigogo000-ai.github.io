# パチスロ帝国 〜ホール経営シミュレーション〜 設計書 (完成系定義)

## 1. ジャンル研究: 何が面白いのか

### シミュレーションゲームの面白さ
1. **システム理解の喜び** — プレイヤーがゲーム内部のルール(モデル)を推測→検証→習熟していく過程そのものが快感。行動と結果が「もっともらしく」つながっていることが必須条件。
2. **意味のある意思決定** — 常に正解の一手が存在せず、トレードオフを天秤にかける判断が求められること。学ばなければ勝てない設計。
3. **創発する物語** — ランダムイベント×システムの掛け算で「あの日ハイエナ軍団が来て…」という自分だけのドラマが生まれる。
4. **箱庭を触れる実感** — 数字の管理だけでなく、育てた対象に直接触れられること。

### 経営(タイクーン)ゲームの面白さ
1. **投資→回収→再投資の複利ループ** — 稼いだ金で店を大きくし、さらに稼ぐ。成長の実感が中核。
2. **リスクとリターンの選択** — 攻めの投資か、守りの蓄財か。
3. **多資源のやりくり** — 金・人・設備・評判など複数リソースの同時管理。どれかを欠くと連鎖的に破綻する。
4. **明瞭なフィードバック** — 帳簿・レポート・グラフで「昨日の判断の結果」が即座に見えること。
5. **目標の階段** — 小目標(今日の黒字)→中目標(拡張)→大目標(1億円)が常に見えていて「あと1日だけ」がやめられない。

## 2. このゲームの完成系

**「出玉設定のジレンマ」を核にした経営シムに、育てた店の実機を自分で遊べる遊技レイヤーを重ねた二層構造。**

### 経営レイヤー(戦略)
- 日次営業ループ: 設定調整 → 営業開始 → 結果レポート → 再投資
- 核となるトレードオフ: 設定を渋れば今日の利益、出せば明日の客(評判)
- 特日(7のつく日): 期待に応えるか裏切るかの定期的な山場
- 新台入替: 人気の経年劣化と新台効果による設備投資サイクル
- 経営資源: 資金 / 評判 / 台(人気・設定) / スタッフ / 広告 / 店舗規模
- ランダムイベント: 天候・ライバル店・攻略誌・故障などの創発要素
- **週次レポート**: 7日ごとに業績サマリーと経営アドバイス(フィードバック強化)
- **実績(称号)システム**: 目標の階段を常に提示
- **帳簿+損益グラフ**: 直近30日の純利益を可視化

### 遊技レイヤー(体験)
- 全機種を**試打**できる(閉店後の試打なので営業収支には影響しない)
- **スロット実機**: レバーON→リール回転→ストップボタン、設定連動のボーナス抽選、
  告知ランプ、G数/BB/RB/差枚カウンター
- **パチンコ実機**: 玉を消費してデジタル回転、リーチ演出、大当り→RUSH(継続率抽選)、
  釘(設定)連動の回転効率、連チャン数表示
- 試打の意義: ①純粋に遊べる ②設定ごとの出方を体感して経営判断に活かせる
  (シミュレーションの「箱庭を触れる」化)

### ゴールとペーシング
- 資金1,000万円スタート → 総資産1億円でクリア(クリア後も継続可)
- 想定クリア日数: 上手なプレイで約90営業日(1日=1クリック+意思決定)
- 破産(資金マイナス)でゲームオーバー

## 3. 数値設計(バランス)

| 項目 | 値 |
|---|---|
| 設定別 店側粗利率 | 設定1: 25% / 2: 21% / 3: 16% / 4: 11% / 5: 5% / 6: -2% |
| 評判変動 | (平均設定-3)×1.4/日 + イベント + 特日ボーナス/ペナルティ |
| 客数 | 収容力(台数×20) × (12% + 評判×0.78%) × 曜日/イベント補正 |
| 客単価 | パチンコ約3.2万円 / スロット約3.8万円 (±20%) |
| 経費 | 家賃3万+台枠2,500円/台 + 人件費1.3万/人 + 光熱費2,500円/台 + 広告 |
| 新台効果 | 導入5日間 人気1.4倍 / 人気は毎日機種固有の速度で低下(下限15) |
| 店舗拡張 | +5台: 200万+30万×既拡張数、上限60台 |
| 特日 | 客数1.7倍、平均設定4以上で評判+4、3未満で評判-6 |

検証方法: Playwrightで3戦略(全台設定1/3/6)×30日 + 最適戦略×150日の
自動プレイを行い、「強欲は短期利益・長期破滅」「大盤振る舞いは赤字」
「バランス経営で約90日クリア」となることを確認する。
