# パチスロ帝国 〜ホール経営シミュレーション〜 設計書 (完成系定義 v3)

## 1. ジャンル研究: 何が面白いのか

### シミュレーションゲームの面白さ
1. **システム理解の喜び** — プレイヤーがゲーム内部のルール(モデル)を推測→検証→習熟していく過程そのものが快感。行動と結果が「もっともらしく」つながっていることが必須条件。
2. **意味のある意思決定** — 常に正解の一手が存在せず、トレードオフを天秤にかける判断が求められること。学ばなければ勝てない設計。
3. **創発する物語** — ランダムイベント×システムの掛け算で「あの日ハイエナ軍団が来て…」という自分だけのドラマが生まれる。
4. **箱庭を触れる実感** — 数字の管理だけでなく、育てた対象に直接触れられること。

### 経営(タイクーン)ゲームの面白さ
1. **投資→回収→再投資の複利ループ** — 稼いだ金で店を大きくし、さらに稼ぐ。成長の実感が中核。
2. **リスクとリターンの選択** — 攻めの投資か、守りの蓄財か。
3. **多資源のやりくり** — 金・人・設備・評判など複数リソースの同時管理。
4. **明瞭なフィードバック** — 帳簿・レポート・グラフで「昨日の判断の結果」が即座に見えること。
5. **目標の階段** — 小目標(今日の黒字)→中目標(拡張)→大目標(1億円)が常に見えていて「あと1日だけ」がやめられない。

## 2. 完成系: 「経営×遊技」の二層構造 + 相互作用する深層システム

**クリア条件: 純資産(資金+台資産−借金)1億円 / 倒産条件: 資金マイナス+融資枠切れ**

### 経営レイヤー(戦略)

コアのジレンマ「出玉設定」を中心に、7つのシステムが相互作用する:

| システム | 内容 | 生むジレンマ |
|---|---|---|
| 客層3種 | 一般客(評判で来店)/常連(高設定日で育つ固定客・客単価1.35倍)/プロ(設定5以上の台に湧き店の金を抜く) | 出す→常連が育つがプロも来る。渋る→今日は儲かるが明日の客が消える |
| 行政ヒート | 平均設定2.6未満の営業でゲージ上昇、8超で25%/日の確率で指導(罰金50万+評判-8) | 回収営業に評判以外の構造的ブレーキ |
| 銀行融資 | 台資産×70%+200万まで借入可、金利0.25%/日。資金ショート時は自動緊急融資 | レバレッジ拡大 vs 利息の複利。借金は純資産から差し引き |
| 週替わりトレンド | 7機種グループのブームが週替わり、該当機種の人気1.4倍 | 新台購入・売却のタイミング読み |
| シマ効果 | 同一機種+6%/台(最大+30%) | 主力機集中 vs バラエティ分散 |
| 交換率 | 等価(集客型)/低換金(粗利+2.5pt・フリ客12%減・常連の足も鈍る) | 店の看板をどちらに振るか |
| 新装開店フェア | 新台導入2日以内・30万・7日毎に1回。翌日客数1.5倍+評判UP | 入替とセットの能動アクション |

さらに: 特日(7のつく日)/スタッフ配置/広告3種/店舗拡張(上限60台)/ランダムイベント7種/週次レポート+アドバイス/実績15種/損益グラフ/難易度3種/クリア評価ランク。

### 遊技レイヤー(体験)
- 全10機種を試打可能(営業収支に影響しない閉店後モード)
- スロット: レバー→リール→3ストップ、設定連動のBIG/REG/小役確率、告知ランプ、差枚カウンター
- パチンコ: デジタル抽選・リーチ演出・RUSH継続率抽選・釘(設定)連動の玉持ち・オート回転
- 意義: ①遊べる箱庭 ②設定ごとの出方を体感→経営判断に還元

## 3. バランス設計(自動プレイ検証済み)

### 検証方法
Playwrightで戦略ボット×各10回×最大200日の自動プレイを実施し、以下を確認:

| 戦略 | 結果(中央値) | 設計意図 |
|---|---|---|
| 最適プレイ(融資+低換金+メリハリ設定+トレンド買い) | **74日クリア = Sランク** | 全システム習熟の報酬 |
| 融資 or 低換金の単体活用 | 84日 = A | テクニックは積み上げ式に効く |
| 基本のメリハリ経営 | 93日 = A | 教科書プレイの基準線 |
| 全台設定3の放置経営 | 生存・200日で資産3,000万(未クリア) | 怠惰は死なないが勝てない |
| 全台設定1の強欲経営 | 行政指導約20回→倒産率100% | 破滅 |
| 全台設定6の大盤振る舞い | プロ+赤字→倒産率100% | 破滅 |
| 難易度 | のんびり88日/標準93日/修羅101日 | 意味のある難易度差 |

- 支配戦略なし(v3調整前は低換金が68日で支配的→客数ペナルティを収容上限クランプ後に適用し84日に是正)
- クリア評価: S≤80日(ほぼ最適プレイのみ)/A≤100/B≤130/C

### 主要数値
| 項目 | 値 |
|---|---|
| 設定別 店側粗利率 | 1: 25% / 2: 21% / 3: 16% / 4: 11% / 5: 5% / 6: -2% (低換金は+2.5pt) |
| 客数 | 一般=収容力(台数×20)×(12%+評判×0.78%)×補正、常連=プール×65%(特日90%)、プロ=高設定台×3人 |
| プロの収支 | 客単価4.5万×(粗利率−16pt) → 設定5で実質-11%、設定6で-18% |
| 常連プール | 平均設定3.4以上+スタッフ充足の日に一般客の2.5%が定着。回収・裏切り・低評判で流出 |
| ヒート | 平均設定2.6未満で+2.2×(2.6−平均)/日、それ以外は×0.65に減衰 |
| 経費 | 家賃(3万+2,500円/台枠)×難易度 + 人件費1.3万/人 + 光熱費2,500円/台 + 広告 + 利息 |
| 難易度係数 | のんびり: 資金1,300万・家賃×0.8・プロ×0.6 / 修羅: 資金700万・家賃×1.35・プロ×1.6 |
