# けもの天下: 物語工房で書き直すための「枠」の一覧

発注者の指示は「物語工房を使って」。物語工房はクラウドのセッションから見えなかった
(リポジトリ・スキル・GitHub のコード検索・PC の共有フォルダを探して、どこにも無かった)ので、
いまの文は Claude が直接書いた **仮の文** になっている。PC のセッションで物語工房にかけて、下の枠の文を差し替える。

## 差し替える場所

| 枠 | 数 | 置き場所 | いつ出るか | 文の形 |
|---|---|---|---|---|
| 始まり | 4(家ごと) | `src/story.js` の `PROLOGUE` | 1 夜目の最初 | 題 + 3〜4 行 |
| 月の語り | 5 × 3 通り | `src/story.js` の `CHAPTERS` | 5・9・13・17・21 夜目。優勢 / 押されている / 互角で文が変わる | 題 + 2〜3 行 |
| 出来事の場面 | 11 | `src/story.js` の `TRIGGERS` | 条件を満たした最初の 1 回だけ(下の表) | 題 + 2〜3 行 |
| 結末 | 5 | `src/story.js` の `ending()` | 決着したとき | 題 + 3〜4 行 |
| 選ぶ出来事 | 14 | `src/core.js` の `EVENTS` | 2 夜に 1 回 | 題 + 本文 1〜2 行 + 選択肢 2 つ + それぞれの結果 1 行 |

## 出来事の場面の条件(`TRIGGERS` の `id`)

`firstTake` はじめて里を取った / `firstLoss` はじめて里を取られた / `homeLost` ほこらを失った / `shrine` ふる社を取った /
`pact` 祟らぬ約束を結んだ / `betrayal` 約束を破った / `hyakkiMe` 百鬼夜行が自分に向いた / `hyakkiOther` よその家に向いた /
`wipe` 家をひとつ消した / `near` あと 1 つで勝ち / `danger` 相手があと 1 つで勝ち

## 結末の条件

`dawn` 約束を結び、破らずに勝った / `cursed` 約束を破って勝った / `lord` だれとも結ばずに勝った /
`swallowed` ほろびた / `endless` よその家が夜の主になった

## 守ること

- 決まり(効果の数字、条件、`id`)は変えない。変えるのは `title` と `lines` と出来事の文だけ
- 1 場面は 360×800 の画面に収まる長さ(いまの上限: 題 + 4 行、1 行は全角 45 字くらいまで)
- 文の中で家の名前を使うときは `myName(s)`(自分の家)や `strongest(s).name`(いちばん強い相手)を使う
- 書き直したら `node test.mjs --mutate`(夜語りの検査 16 件を含む)と `node build.mjs`
