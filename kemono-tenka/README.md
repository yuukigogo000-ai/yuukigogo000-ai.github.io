# けもの天下

朝が来なくなった山里で、12 の里の灯を 4 つのけものの家(鬼熊・沼主・妖狐・白兎)が取り合う、怪談仕立ての小さな国盗りゲーム。1 回 10〜15 分。
信長の野望・シヴィライゼーション系を広く調べた結果(`../reports/戦略ゲーム先行事例リサーチ.md`)から、骨格を決めた。

2026-11-15 に、発注者の指示で題材を **和風の怪談** に替え、**夜語り**(遊びの進み方に合わせて物語が書き進む仕組み)を足した。
決まりと数字は替えていない(呼び名だけ: 米→灯、兵→もののけ、城→結界、国→里、都→ふる社、包囲網→百鬼夜行、家臣→憑きもの、進言→お告げ、ターン→夜、年→月)。

> **思い込みで進めた点:** 指示は「シナリオライツシステムつかって」。その名前の道具はこのリポジトリにも、このセッションから見える場所にも
> 見つからなかったので、「遊びの進み方に合わせて物語が書き進む仕組み」と読んで `src/story.js` として作った。
> PC 側にある特定の道具のことなら、`story.js` の 2 つの関数(`storyDue` / `ending`)を差し替えれば済む作りにしてある。

## 夜語り(`src/story.js`)

- **始まり**: 選んだ家ごとに違う語り(4 つ)
- **月の語り**: 月が変わるたびに 1 つ(5 つ)。同じ月でも、優勢・互角・押されているで文が変わる
- **出来事の場面**: 遊びの中で起きたことに応じて入る(11 個)。はじめて里を取った / 取られた / ほこらを失った / ふる社を取った /
  祟らぬ約束を結んだ / 破った / 百鬼夜行が自分に向いた / よその家に向いた / 家をひとつ消した / あと 1 つで勝ち / 相手があと 1 つ
- **結末**: 5 つ。約束を守って勝つ「夜明け」/ 約束を破って勝つ「影のない朝」/ だれとも結ばずに勝つ「夜の主」/ ほろびる「のまれる」/
  よその家が主になる「明けない夜」。見た結末はタイトルに「見た結末: n / 5」と出る
- 同じ場面は 1 回の遊びで二度語らない。1 度に語るのは 2 つまで。語った場面は盤面と一緒に保存される
- 怖さは「静かで不穏」の側に寄せた(血や痛みの描写はなし)。ひらがな多めの、子どもも読める言葉で書いてある

| 調査で分かったこと | このゲームでの形 |
|---|---|
| 領土が増えるほど入力が増え、後半が作業になる | 命令は 1 夜に 3 つだけ。里が増えても変わらない |
| 勝敗は全体の 2/3〜3/4 で決まり、残りは消化試合。Civ VI を最後まで遊ぶ人は半分未満 | 12 の里のうち 7 つを取った瞬間に決着。長くても 24 夜(6 つの月) |
| 読めない AI・ズルい AI が一番嫌われる | 相手の家は、次に何をするかを地図に出す。攻めは必ず予告される。性格は固定で、画面に書いてある |
| 外交がでたらめに見える | 仲は -5〜+5 の数字で見える。約束を破ると、すべての家の仲が下がる |
| 一人勝ちが止まらない。隠れた補正は恨まれ、見える決まりは受け入れられる | 5 つ以上の単独首位には百鬼夜行(自分にも相手にも同じ決まり) |
| いくさを別のゲームにすると、どちらも中途半端になる | あらそいは自動。勝ち負けと残るもののけは、出す前に分かる(運なし) |
| 出来事は、数を増やすほど良くなる数少ない要素 | 2 夜に 1 回、2 つから選ぶ怪談めいた出来事(14 種。結果は言葉で返す) |
| 家臣の提案を一覧で見せる作りは好評 | 「お告げ」: いま良さそうな命令を 3 つ、理由つきで出す |

## 遊び方

- 里をタップして命令を選ぶ。自分の里を選んでからとなりの里をタップすると夜行(攻める・もののけを動かす)
- 命令: 夜行 / 呼び寄せ(もののけ 1 つにつき灯 1、1 回 4 まで)/ 灯入れ(灯 4 で灯の数 +1)/ 結界張り(灯 3 で結界 +1)/ 供え物(灯 2 で仲 +2)/ 祟らぬ約束(4 夜のあいだ攻め合わない)
- 灯は、持っている里の灯の数だけ毎夜増え、もののけ 4 つにつき灯 1 がかかる。ふる社を持つと灯 +2
- 憑きものは 4 人まで。家ごとに看板の憑きものがいて、出来事や、相手の家を消すことで増える
- 最初の月は、どの家も、ほかの家のほこら(本拠)を攻められない
- 「きょうの夜」は、その日の日付で決まる同じ並びに挑戦するモード。途中の遊びは端末に保存され、続きから遊べる

## 確かめたこと(2026-11-15、題材を替えたあと)

- `node test.mjs --mutate`: 85 件合格(うち夜語りが 16 件)。300 回適当に遊んでも必ず決着がつくこと、途中で保存して読み直しても結果が同じこと、
  何もしなくても最初の月のうちに負けないこと、200 回遊んでも語りがくり返されず壊れた文がないこと(保存をはさんでも)を含む。
- `node balance.mjs 200`(模擬の打ち手。各 200 回、4 つの家を順に使う)。題材を替える前と同じ数字(決まりは替えていない):

| 打ち手 | やさしい | ふつう | むずかしい |
|---|---|---|---|
| お告げの一番上に従う | 95% | 80% | 47% |
| お告げの上位 3 つから適当に選び、2 割は何もしない | 21% | 11% | 1% |
| 何もしない | 0% | 0% | 0% |

  決着は平均 14〜18 夜目。24 夜の時間切れまで行くのは、お告げに従う打ち手で 4〜7%。
- 実ブラウザ(360×800 / 390×844、4 つの家): タイトル → 始まりの語り → 決着 → 結末の画面まで通しで動き、エラーなし、はみ出しなし。
  1 回の遊びで語られた場面は 4〜13。手でのタップ(里を選んで呼び寄せ、となりをタップして夜行の確かめ)、オフラインでの再読み込みと続きからの再開も確認。
- 色は夜の 1 種類だけにした(明るい版は無い)。端末が明るい設定でも同じ見た目になる。

## 分かっていないこと

- **人が遊んだときの難しさと面白さ。** 数字は模擬の打ち手のもの。「お告げに従えば勝てる」ので、お告げが強すぎて考える余地を奪っている可能性がある
- 適当に選ぶ打ち手の勝率が低い(やさしいでも 2 割)。気軽に遊ぶ人には厳しいかもしれない
- 地図は 1 種類だけ。何回か遊ぶと攻め方が固まるおそれがある(調査でも、小型の戦略ゲームの弱点として挙がっていた)
- 相手の家同士の外交はない(百鬼夜行だけ)
- **文章が怖いか、読みたくなるか。** 人に読んでもらっていない。語りは全部で 25 場面で、何回か遊ぶと同じ文に当たる
- 語りが入る回数(1 回の遊びで 4〜13 回)が、遊びの流れを止めすぎていないか
