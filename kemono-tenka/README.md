# けもの天下

12 の国を 4 つのけもの家が取り合う、小さな国盗りゲーム。1 回 10〜15 分。
信長の野望・シヴィライゼーション系を広く調べた結果(`../reports/戦略ゲーム先行事例リサーチ.md`)から、骨格を決めた。

| 調査で分かったこと | このゲームでの形 |
|---|---|
| 領土が増えるほど入力が増え、後半が作業になる | 命令は 1 ターンに 3 つだけ。国が増えても変わらない |
| 勝敗は全体の 2/3〜3/4 で決まり、残りは消化試合。Civ VI を最後まで遊ぶ人は半分未満 | 12 国のうち 7 国を取った瞬間に決着。長くても 24 ターン(6 年) |
| 読めない AI・ズルい AI が一番嫌われる | 相手の家は、次に何をするかを地図に出す。攻めは必ず予告される。性格は固定で、画面に書いてある |
| 外交がでたらめに見える | 仲は -5〜+5 の数字で見える。約束を破ると、すべての家の仲が下がる |
| 一人勝ちが止まらない。隠れた補正は恨まれ、見える決まりは受け入れられる | 5 国以上の単独首位には包囲網(自分にも相手にも同じ決まり) |
| いくさを別のゲームにすると、どちらも中途半端になる | いくさは自動。勝ち負けと残る兵は、出す前に分かる(運なし) |
| 出来事は、数を増やすほど良くなる数少ない要素 | 2 ターンに 1 回、2 つから選ぶ出来事(14 種。結果は言葉で返す) |
| 家臣の提案を一覧で見せる作りは好評 | 「家臣の進言」: いま良さそうな命令を 3 つ、理由つきで出す |

## 遊び方

- 国をタップして命令を選ぶ。自分の国を選んでからとなりの国をタップすると出陣
- 命令: 出陣(攻める・兵を動かす)/ 徴兵(兵 1 つにつき米 1、1 回 4 まで)/ 開発(米 4 で石高 +1)/ 築城(米 3 で城 +1)/ 贈り物(米 2 で仲 +2)/ 不戦の約束(仲 +2 以上、米 2、4 ターン)
- 米は石高の合計だけ毎ターン増え、兵 4 つにつき米 1 の維持費がかかる。都を持つと米 +2
- 家臣は 4 人まで。家ごとに看板の家臣がいて、出来事や、相手の家をほろぼすことで増える
- 最初の 1 年は、どの家も、ほかの家の本拠を攻められない
- 「きょうの乱」は、その日の日付で決まる同じ並びに挑戦するモード。途中の遊びは端末に保存され、続きから遊べる

## ファイル

| ファイル | 中身 |
|---|---|
| `src/core.js` | ルール・相手の家の考え方・出来事・進言。依存なし。乱数は盤面の中の種だけ |
| `src/ui.js` + `src/page.html` | 画面と入力(見た目は仮) |
| `build.mjs` | 1 ファイルに組み立てる → `index.html` と `artifact.html` |
| `sw.js` / `manifest.webmanifest` / `icon.svg` | オフライン対応 |
| `test.mjs` | 検査。`node test.mjs --mutate` |
| `balance.mjs` | バランス確認。`node balance.mjs [回数]` |
| `browser-check.mjs` | 実ブラウザでの通しプレイとオフライン確認。`NODE_PATH=$(npm root -g) node browser-check.mjs` |

## 確かめたこと(2026-11-15)

- `node test.mjs --mutate`: 69 件合格。300 回適当に遊んでも必ず決着がつくこと、途中で保存して読み直しても結果が同じこと、
  何もしなくても最初の 1 年のうちに負けないことを含む。
- `node balance.mjs 200`(模擬の打ち手。各 200 回、4 つの家を順に使う):

| 打ち手 | やさしい | ふつう | むずかしい |
|---|---|---|---|
| 進言の一番上に従う | 95% | 80% | 47% |
| 進言の上位 3 つから適当に選び、2 割は何もしない | 21% | 11% | 1% |
| 何もしない | 0% | 0% | 0% |

  決着は平均 14〜18 ターン目。6 年の時間切れまで行くのは、進言に従う打ち手で 4〜7%。
- 実ブラウザ(360×800 / 390×844、明暗、4 つの家): タイトルから決着まで通しで動き、エラーなし、はみ出しなし。
  手でのタップ(国を選んで徴兵、となりをタップして出陣の確かめ)、オフラインでの再読み込みと続きからの再開も確認。

## 分かっていないこと

- **人が遊んだときの難しさと面白さ。** 数字は模擬の打ち手のもの。「進言に従えば勝てる」ので、進言が強すぎて考える余地を奪っている可能性がある
- 適当に選ぶ打ち手の勝率が低い(やさしいでも 2 割)。気軽に遊ぶ人には厳しいかもしれない
- 地図は 1 種類だけ。何回か遊ぶと攻め方が固まるおそれがある(調査でも、小型の戦略ゲームの弱点として挙がっていた)
- 相手の家同士の外交はない(包囲網だけ)
