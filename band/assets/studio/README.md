# SETLISM Stage Studio assets

Created for this project using the built-in imagegen tool. No reference photographs,
logos, commercial typefaces or third-party image packs were used. Original generated
PNGs were converted to WebP for delivery; the transparent illustration keeps alpha.
Interactive text, buttons, meters and charts are HTML/CSS/SVG, not baked into images.

| File | Purpose |
| --- | --- |
| `stage-hero.webp` | Panoramic, dark empty stage with warm amber light and left-side negative space |
| `rehearsal.webp` | Guitar and amplifier in a warm, quiet rehearsal studio |
| `empty-setlist.webp` | Transparent blank setlist, pick and instrument cable for the empty state |

## Generation briefs

- Hero: cinematic editorial photograph of an empty small live venue immediately before
  a band walks onstage; drum kit, guitar amplifier and microphone stands; amber lights
  through fine haze; 3:1 panoramic framing with a dark left half for the live heading;
  no people, text, logos, watermarks or UI.
- Rehearsal: editorial close-up of an unbranded guitar on a stand beside a compact
  amplifier; charcoal acoustic panels, amber rim lighting and real tactile materials;
  3:2 landscape with negative space on the left; no people, text, logos or UI.
- Empty state: premium three-quarter overhead still-life of a blank ivory setlist
  sheet, charcoal pick and loosely curved instrument cable; understated amber edges,
  compact composition, true transparent background; no text, numbers or logos.

The separate concept mockup establishes the visual direction only. Its fictional
content and illustrated controls are not app data or proof of functionality.

Final edit brief: remove all logo-like lettering from the guitar headstock and bass
drum head, keeping composition, lighting and materials. Both photographic assets
received this targeted built-in imagegen edit before WebP encoding.
