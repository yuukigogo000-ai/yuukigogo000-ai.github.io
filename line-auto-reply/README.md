# LINE自動返信ボット セットアップ手順（無料・サーバー不要）

キーワードに応じて自動返信するLINEボットです。
**Google Apps Script（GAS）** を使うので、サーバー代は一切かからず、Googleアカウントがあれば動きます。

- 「営業時間」と送られたら → 営業時間を返信
- 「予約」と送られたら → 予約案内を返信
- どれにも当てはまらなければ → 案内メッセージを返信（返信しない設定も可）
- 友だち追加時のあいさつメッセージも送れます

返信の内容は `code.gs` の先頭にある **設定エリア** を書き換えるだけで変更できます。

---

## 全体の流れ（所要時間：約20〜30分）

1. LINE公式アカウント（Messaging APIチャネル）を作る
2. GASプロジェクトを作ってコードを貼る
3. GASを「ウェブアプリ」として公開する
4. チャネルアクセストークンをGASに保存する
5. LINE側にWebhook URLを設定する
6. 動作確認

---

## 手順1. LINE Messaging APIチャネルを作る

1. [LINE Developersコンソール](https://developers.line.biz/console/) にLINEアカウントでログイン
2. 「プロバイダー」を新規作成（名前は自分の名前や屋号でOK）
3. 「Messaging API」チャネルを作成
   - ※ 2024年秋以降は、先に [LINE公式アカウント](https://entry.line.biz/) を作ってから、
     [LINE公式アカウント管理画面](https://manager.line.biz/) → 設定 → Messaging API で有効化する流れになっています。
     画面の案内に従って進めてください。
4. 作成できたら、チャネルの **「Messaging API設定」タブ** を開いておく（あとで使います）

## 手順2. GASプロジェクトを作る

1. [script.google.com](https://script.google.com/) を開き「新しいプロジェクト」
2. プロジェクト名を「LINE自動返信」などに変更
3. 最初から入っている `function myFunction() {...}` を全部消して、
   この同じフォルダにある **`code.gs` の中身を全部コピーして貼り付け**
4. 保存（Ctrl+S / ⌘S）

## 手順3. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 歯車アイコン →「ウェブアプリ」を選択
3. 次のように設定：
   - 説明：任意（例「v1」）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員** ←ここ重要！（LINEのサーバーから呼ばれるため）
4. 「デプロイ」→ 初回はGoogleアカウントの承認を求められるので許可する
   - 「このアプリはGoogleで確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」で進めます
5. 表示された **ウェブアプリのURL（https://script.google.com/macros/s/～/exec）をコピー**しておく

> ⚠️ 以後、コードを修正したときは「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →
> バージョンを「新バージョン」にして「デプロイ」してください。
> **保存しただけでは公開中のボットに反映されません。**

## 手順4. チャネルアクセストークンを保存する

1. LINE Developersの「Messaging API設定」タブの一番下、
   **「チャネルアクセストークン（長期）」の「発行」** を押してトークンをコピー
2. GASのエディタに戻り、`setToken` 関数の中の `'ここにトークンを貼る'` を、
   コピーしたトークンに書き換える
3. エディタ上部の関数選択メニューで **`setToken` を選んで「実行」**
4. 実行が終わったら、**貼り付けたトークンを `'ここにトークンを貼る'` に戻して保存**
   （トークンはGASの「スクリプトプロパティ」に安全に保存済みなので、コード内に残さない）
5. 確認：関数選択で **`checkToken` を選んで「実行」** → ログに「トークン設定OK」と出れば成功

## 手順5. LINE側にWebhook URLを設定する

1. LINE Developersの「Messaging API設定」タブで：
   - **Webhook URL**：手順3でコピーしたウェブアプリのURLを貼って「更新」
   - **Webhookの利用**：ON
   - 「検証」ボタンを押して「成功」と出ればOK
2. **応答メッセージをOFFにする**（これをしないとLINE標準の自動応答とぶつかります）
   - [LINE公式アカウント管理画面](https://manager.line.biz/) → 設定 → 応答設定
   - 「応答メッセージ」→ **オフ**
   - 「Webhook」→ **オン**
   - あいさつメッセージもGAS側で送る場合は「あいさつメッセージ」も **オフ**

## 手順6. 動作確認

1. 「Messaging API設定」タブにあるQRコードを自分のLINEで読み取り、友だち追加
2. 「営業時間」と送ってみる → 営業時間の案内が返ってくれば完成！🎉

## 返信内容のカスタマイズ

`code.gs` の先頭にある設定エリアを書き換えます。

```js
const RULES = [
  {
    keywords: ['営業時間', '何時まで'],   // どれかが含まれていたら反応
    reply: '返信したい文章。\n←これで改行できます',
  },
  // ルールは何個でも追加OK。上から順にチェックされます。
];
```

- **どのルールにも当てはまらないとき返信させたくない** → `DEFAULT_REPLY = null;` にする
- **友だち追加時のあいさつを無くしたい** → `FOLLOW_GREETING = null;` にする
- 書き換えたら保存し、**手順3の⚠️のとおり「新バージョン」で再デプロイ**するのを忘れずに！

## よくあるトラブル

| 症状 | 原因と対処 |
|---|---|
| 何も返ってこない | ①手順5-2の「応答メッセージOFF・WebhookON」を確認 ②GASのデプロイ設定が「全員」になっているか確認 ③`checkToken` を実行してトークンを確認 |
| 「検証」で失敗する | ウェブアプリURLが `/exec` で終わっているか確認（`/dev` はNG） |
| コードを直したのに反映されない | 「新バージョン」で再デプロイが必要（保存だけではダメ） |
| LINEの定型応答が混ざって返ってくる | 応答設定の「応答メッセージ」がまだONになっている |
| エラーの詳細を見たい | GASエディタ左メニューの「実行数」で `doPost` の実行ログを確認 |

## 料金について

- **GAS**：無料（個人利用の範囲なら制限に達することはまずありません）
- **LINE Messaging API**：無料プランで月200通まで「プッシュ送信」可能。
  ただしこのボットが使う **「応答（リプライ）」はカウント対象外で無制限・無料** です。

## 注意（セキュリティ）

- GASのウェブアプリはリクエストヘッダーを受け取れない仕様のため、LINE署名（X-Line-Signature）の検証はしていません。URLを推測される可能性は極めて低いですが、業務で本格利用する場合はCloudflare WorkersやNode.jsサーバーへの移行を検討してください。
- チャネルアクセストークンは絶対に公開リポジトリにコミットしないでください（この手順ではスクリプトプロパティに保存するので安全です）。
