- 各チャートの左上に太字ラベル `体重` / `血圧`、その下に `(kg)` / `(mmHg)` を小さく

- 血圧: **収縮期=red実線**、**拡張期=teal破線(`stroke-dasharray:4 3`)**、右上に凡例 `— 収縮期  --- 拡張期`。右端に最新値 `138`(red) `88`(teal)。※系列色の文字はこのデザインの指定なので採用(白地でのコントラストは両色とも4.5:1超)

### 2.8 セクション5「健康診断」
- 表: 列 `項目 ／ 今年 ／ 去年 ／ 判定`。「今年/去年」は最新健診と前回健診の年が今年/去年ならその表記、違えば西暦4桁を出す。前回が無ければ「去年」列は `—`
- 行は入力済みの `CHK_METRICS` 全部(γ-GTP/中性脂肪/HDL/LDL/空腹時血糖/HbA1c/尿酸値)。項目名は短く(`γ-GTP` `尿酸` `HbA1c` `中性脂肪` `HDL` `LDL` `血糖`)、単位は`title`へ
- **判定バッジの規則**(新規。既存`JUDGE_BADGE`は置き換えてよい):
  ```
  lvl = CHK_METRICS[m].judge(v)             // 0 基準内 / 1 要注意 / 2 要相談
  better = HDLは大きいほど良い、それ以外は小さいほど良い
  rel   = |v - prev| / prev                  // prevが無ければ null
  if lvl == 2                     → 「要相談」  red塗り・白字
  elif rel != null && better && rel >= 0.05 → 「改善」   teal塗り・白字
  elif lvl == 1 && rel != null && !better && rel >= 0.05 → 「注意」 orange塗り・白字
  elif lvl == 1 && rel == null    → 「注意」   orange塗り
  elif lvl == 1                   → 「経過観察」 navy枠線
  else                            → 「基準内」 teal枠線
  ```
  参照画像の例で検算: γ-GTP 68 vs 82(lvl1・17%改善)→改善 ✓ / 尿酸 7.3 vs 6.8(lvl1・7%悪化)→注意 ✓ / HbA1c 5.7 vs 5.6(lvl1・1.8%)→経過観察 ✓
- 表の下に `<details>`「＋ 健診結果を入力・編集」(現行フォームと削除ボタン)。未入力時は表の代わりに現行の案内文
