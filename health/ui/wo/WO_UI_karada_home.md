## 0. 目的

風呂上がりと晩酌中に**片手で・酔っていても・暗い部屋でも**開いて1タップで終わる形にする。数値は「大きく1つ」、判定は色だけでなく**帯の上の位置**で分かるようにする。

## 2. 交通整理(Claude が決定 → 発注者に提示・拒否権)

| 問い | 決定 | 理由 |
|---|---|---|
| **主操作は1つだけ、何?** | **今日の数値を記録して保存する** | 毎日1回必ず発生し、これが無いと判定・グラフ・継続が全部成立しない。晩酌カウンターは保存ボタンを持たない即時操作なので主操作にはせず、指の届く位置に置く |
| 上位3タスク(頻度順) | ①晩酌を1タップ加算/休肝日を確定 ②今日の記録を保存 ③今の判定と推移を見る | ①は回数最多だが1タップで完結。②は所要時間が最長=画面の主役。③は受動 |
| 格下げ/隠す | 記録一覧60件(折りたたみ)・設定/身長/目標/健診日/CSV(左ドロワー)・健診入力(折りたたみ)・川柳とコーチ(あいさつ下の1行+ベル)・腹囲の独立グラフ(廃止)・BMI(体重カードの補足行へ) | 毎日見る必要がない。初期表示に主操作と今日の判定だけを残す |

## 5. デザイン仕様(実装した形)

- **外殻**: 上部固定バー(56px・ハンバーガー/タイトル/ベル+赤ドット)、下部固定タブ(ホーム/記録/推移/健診・56px・Safe Area)。タブは押した瞬間に現在地が移り、手スクロール時はヘッダー下に来たセクションを現在地とする
- **あいさつ**: 日付 → 時間帯であいさつ → コーチの一言(無ければ今日の一句)1行
- **曜日ストリップ**: 直近7日・記録がある日に点・今日は主色のピル(表示専用)
- **今日の状態**: 4枚の縦積みカード。各カード = アイコン+ラベル → 特大数値+単位 → 判定ピル/前週比 → **帯マーカー**(両端に語・基準位置に目盛) → 理由の一文
  - 体重: BMI 17〜33 の帯・25 に目盛 / 腹囲: 75〜100・85 に目盛 / 血圧: 収縮期 100〜180・140 に目盛 / 今週の酒: 0〜280g のメーター・140g に目盛
- **記録継続**: 主色ベタのカード。日数(特大)+役職チップ+次の役職まで
- **晩酌**: 2×2 の 88px ボタン(グラスのSVG+名前+`+1`、押した数は右上に `×2`)。集計行 → やり直す/その他のお酒 → 全幅の「休肝日で確定」(確定済みなら「休肝日を取り消す」)
- **今日の記録**: 行 = ラベル(86px)+右寄せ入力+単位。血圧のみ2枠を `／` で挟む。全幅「記録を保存」→ 保存メッセージ(3秒)
- **推移**: 体重(実測=淡い線+7日移動平均=実線と最新値ラベル・目標は点線)/ 血圧(収縮期=実線・拡張期=破線・色ドット凡例・最新値ラベル)。X軸は最初/中央/最新の3つだけ
- **健診**: 項目/今年/去年/判定の4列。基準外の数値だけ着色。判定は 改善/注意/経過観察/要相談/基準内 の枠線ピル
- **ドロワー(≡)**: 身長・目標体重・次の健診日 + CSV書出/読込 + 免責。**お知らせ(🔔)**: 健診カウントダウン・コーチ・BMI・今日の一句
