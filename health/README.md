# yuukigogo000-ai.github.io

## カラダ日報 — `/health/`

40〜50代の男性向けの健康記録アプリ。サーバー不要・インストール不要、単一の HTML ファイルで動きます。データは端末のブラウザ(localStorage)にだけ保存され、外部への通信はゼロです。

**URL(公開後):** https://yuukigogo000-ai.github.io/health/

### 機能

- **今日の状態** — 体重・腹囲・血圧・今週の純アルコール・記録継続を、**帯の上のマーカー位置**で判定表示(色だけに頼らない)。判定の下には必ず理由の一文を出す
- **メタボ判定** — 特定健診(男性)の基準。腹囲85cm以上 + 血圧/脂質/血糖のリスク数で「該当 / 予備群 / 腹囲オーバー / セーフ」
- **晩酌カウンター** — ビール・ハイボール・日本酒・ワインを1タップで加算し、**純アルコールg**に換算。週140g(厚労省の目安×7日)のメーター。「休肝日で確定」と取り消し、押し間違いの「やり直す」つき
- **今日の記録** — 体重・腹囲・血圧・歩数・睡眠・メモ。同じ日に再保存すると空欄は既存値を残す
- **30日の推移** — 体重は実測+7日移動平均の2本(日々のブレと傾向を分ける)、目標は点線。血圧は収縮期/拡張期の2本
- **健康診断** — γ-GTP・中性脂肪・HDL・LDL・血糖・HbA1c・尿酸を年ごとに記録し、前回比で 改善/注意/経過観察/要相談/基準内 を判定
- **記録継続で出世** — 研修中 → 平社員 → 主任 → 係長 → 課長 → 部長 → 専務 → 会長
- **CSV** — 日次・健診それぞれ書き出し / 読み込み(機種変更前に)

### 技術メモ

- Vanilla JS の単一ファイル。**外部依存ゼロ**(CDN・Webフォント・外部アイコンなし)。アイコンは自前のインラインSVG、フォントは system-ui
- 見た目は `~/.claude/playbooks/UI_PLAYBOOK.md` の手順で作成。見本= Google Stitch(Material Design 3・シード色 1C3160)3案 + App Store の実在アプリ8本47枚。色は `:root` のトークンだけに置き、ライト/ダーク両対応
- 機械検査 `uicheck` で GREEN(タップ44px未満 0件・コントラスト不足 0件・文字サイズ5種・角丸2種)。基準線 `health/ui/baselines/karada.json`
- Playwright のスモークテスト38項目(`health/tests/smoke.mjs`)。`--mutate` で判定基準をわざと壊し、テストが本当に落ちることを確認できる
- 判定はいずれも目安です。診断・治療は医師にご相談ください
