# APP RANK ALPHA v0.1

日本の App Store / Google Play の Top Grossing(Games)ランキングから、上場モバイルゲーム企業の業績変化を先取りできるか、
そしてそれが株価に遅れて反映されるかを検証する研究プロジェクト。

- 仕様(正本・変更禁止): `config/APP_RANK_ALPHA_v0.1_CANONICAL.md`(SHA256: `config/SPEC_SHA256.txt`)
- 計画書: `PLAN.md`
- 実装者の運用規約: `AGENTS.md`
- 起動プロンプト: `KICKOFF_PROMPT.md`

このディレクトリは GitHub Pages から配信されない(`_config.yml` の `exclude`)。
`data/` 配下(プロバイダ由来データ)はコミットしない(`.gitignore`)。
